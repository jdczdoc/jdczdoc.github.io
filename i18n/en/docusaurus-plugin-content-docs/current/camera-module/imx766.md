# IMX766 Camera Module

## Overview

The Sony IMX766 is a 50-megapixel-class back-illuminated stacked CMOS image sensor. It uses a Quad Bayer color filter array and supports PDAF, pixel binning, high-frame-rate output, and DOL HDR.

The available document is the IMX766 sensor specification. It does not define a specific camera module lens, FPC, connector, or mechanical dimensions, so this page lists only confirmed sensor parameters.

## Main Specifications

| Item | Specification |
| --- | --- |
| Image sensor | Sony IMX766-AAJH5-C |
| Sensor type | Color CMOS, back-illuminated stacked structure |
| Color filter array | Quad Bayer Coding |
| Effective pixels | 8224 × 6224, approximately 51.1 megapixels |
| Active pixels | 8192 × 6144, approximately 50.3 megapixels |
| Optical format | 1/1.56 inch |
| Pixel size | 1.00 μm × 1.00 μm |
| Chip size | 9.214 mm × 7.270 mm |
| Output format | RAW10 / RAW8 |
| Phase detection autofocus | 2 × 2 OCL PDAF |
| Image correction | Dynamic defect-pixel correction and lens-shading correction |
| HDR | Two-exposure and three-exposure DOL |
| OTP | 4 Kbit available to users |
| Temperature sensor | Integrated |
| Dual-sensor synchronization | Master and slave synchronization supported |

## Data Interface

| Item | Specification |
| --- | --- |
| Image interface | MIPI CSI-2 |
| MIPI D-PHY | Two or four lanes, up to 2.5 Gbps per lane |
| MIPI C-PHY | One, two, or three trios, up to 3.1 Gsps per trio |
| D-PHY version | 1.2 |
| C-PHY version | 1.2 |
| Control interface | I2C Fast-mode, I2C Fast-mode Plus, and I3C |
| I2C register address width | 16 bits |
| I2C data width | 8 bits |
| External input clock, INCK | 6 MHz to 27 MHz |

## Typical Resolution and Frame Rate

The maximum frame rate depends on the selected MIPI physical layer.

| Mode | Resolution | C-PHY Maximum | D-PHY Maximum |
| --- | ---: | ---: | ---: |
| Full resolution | 8192 × 6144 | 24 fps | 10 fps |
| Full-resolution 16:9 crop | 8192 × 4608 | 24 fps | 10 fps |
| 2 × 2 adjacent-pixel binning | 4096 × 3072 | 120 fps | 40 fps |
| 2 × 2 binning, 16:9 | 4096 × 2304 | 120 fps | 40 fps |
| V2H2 high-speed mode | 2048 × 1536 | 360 fps | 120 fps |
| V2H2 high-speed mode, 16:9 | 2048 × 1152 | 480 fps | 160 fps |
| Two-exposure DOL | 4096 × 3072 | 60 fps | 20 fps |
| Three-exposure DOL | 2048 × 1152 | 60 fps | 20 fps |

Whether a finished module and SoC platform can reach these modes also depends on module routing, the MIPI PHY, ISP bandwidth, and driver register configuration.
