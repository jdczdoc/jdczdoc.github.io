# OV5695 Camera Module

## Overview

The RF-OV5695-JD01 V1.0 camera module uses the OmniVision OV5695 color CMOS image sensor and provides 5-megapixel image output.

The module drawing shows a 30-pin FPC connector. Two MIPI data lanes are connected, together with the MIPI clock pair, I2C, MCLK, PWDN, and three sensor power rails.
