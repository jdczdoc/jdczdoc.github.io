# IMX415 Camera Module

## Overview

The IMX415-98 IR-CUT camera module uses the Sony IMX415 image sensor and supports 3840 × 2160 output.

This page contains only the camera-module and lens specifications. Development-board connection, driver configuration, and test commands are intentionally omitted.

## Module Specifications

| Item | Specification |
| --- | --- |
| Module name | IMX415-98 IR-CUT Camera |
| Image sensor | Sony IMX415 |
| Effective resolution | Approximately 8.29 megapixels |
| Output resolution | 3840 × 2160 |
| CMOS optical format | 1/2.8 inch |
| Diagonal size | 6.43 mm |
| Pixel size | 1.45 μm × 1.45 μm |
| IR-CUT | Supported |

## Lens Parameters

| Item | Specification |
| --- | --- |
| Focal length | 3.95 mm |
| Aperture | F2.0 |
| Diagonal field of view | 98° |
| Horizontal field of view | 84° |
| Vertical field of view | 44° |
| Distortion | Less than 1% |

## Documentation Scope

The reference page does not provide the module's MIPI lane count, FPC pinout, or complete mechanical dimensions, so those values are not added here.
