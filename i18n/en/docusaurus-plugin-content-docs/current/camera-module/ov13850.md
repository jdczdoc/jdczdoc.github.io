# OV13850 Camera Module

## Overview

The OV13850 camera module uses the OmniVision OV13850 color CMOS image sensor and supports image output up to 4224 × 3136 pixels.

## Main Specifications

| Item | Specification |
| --- | --- |
| Image sensor | OmniVision OV13850 |
| Sensor type | Color CMOS, rolling shutter |
| Active pixel array | 4224 × 3136 |
| Resolution | Approximately 13.2 megapixels |
| Optical format | 1/3.06 inch |
| Pixel size | 1.12 μm × 1.12 μm |
| Output format | 10-bit RAW RGB |
| Data interface | MIPI CSI-2 |
| MIPI lanes | 1, 2, or 4 lanes |
| Maximum lane rate | 1200 Mbps per lane |
| Control interface | SCCB |
| Input clock | 6 MHz to 64 MHz |
| Maximum frame rate | 4224 × 3136 at 30 fps |
| Mirror and flip | Supported |
| Cropping and windowing | Supported |
| HDR | Alternate Row HDR |
| OTP memory | Integrated 8 Kbit OTP |
| Temperature sensor | Integrated |

## Resolution and Frame Rate

| Mode | Resolution | Maximum Frame Rate | MIPI Configuration |
| --- | ---: | ---: | --- |
| Full resolution | 4224 × 3136 | 30 fps | 4 lanes, 1200 Mbps/lane |
| 16:9 mode | 4224 × 2376 | 30 fps | 4 lanes, 1200 Mbps/lane |
| 2 × 2 binning | 2112 × 1568 | 60 fps | 4 lanes, 640 Mbps/lane |
| EIS 1080P | 2112 × 1188 | 60 fps | 4 lanes, 640 Mbps/lane |
| EIS 720P | 1408 × 792 | 60 fps | 4 lanes, 640 Mbps/lane |
| 720P | 1280 × 720 | 120 fps | 4 lanes, 640 Mbps/lane |
