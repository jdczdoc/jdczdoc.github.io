# OV13855 Camera Module

## Overview

The RF13855-JD01 V1.0 camera module uses the OmniVision OV13855 color CMOS image sensor. It provides a four-lane MIPI CSI-2 image interface and uses I2C for sensor register control.

## Main Specifications

| Item | Specification |
| --- | --- |
| Module model | RF13855-JD01 V1.0 |
| Image sensor | OmniVision OV13855 |
| Sensor type | Color CMOS, rolling shutter |
| Resolution | Approximately 13 megapixels |
| Common output resolution | 4224 × 3136 |
| Sensor active pixel array | 4256 × 3168 |
| Optical format | 1/3.06 inch |
| Pixel size | 1.12 μm × 1.12 μm |
| Pixel technology | PureCel Plus |
| Data interface | MIPI CSI-2 |
| MIPI configuration | Four data lanes and one differential clock pair |
| Control interface | I2C through SDA and SCL |
| Autofocus supply | AF-VDD pin provided |
| Phase detection autofocus | PDAF supported |
| Image orientation | Horizontal mirror and vertical flip supported |

## Resolution and Frame Rate

| Output Mode | Resolution | Maximum Frame Rate |
| --- | ---: | ---: |
| Full resolution | 4224 × 3136 | 30 fps |
| Full HD | 1920 × 1080 | 60 fps |
| HD | 1280 × 720 | 90 fps |

## Electrical Interface

| Supply or Signal | Specification |
| --- | --- |
| DOVDD | 1.8 V or 2.8 V |
| AVDD | 2.8 V |
| DVDD | 1.2 V |
| AF-VDD | Exposed by the module; voltage depends on the fitted actuator |
| XCLK | External sensor clock input |
| RESET | Hardware reset |
| PWDN | Hardware power-down control |
| SDA / SCL | I2C control bus |

## 26-Pin Connector

| Pin | Signal | Pin | Signal |
| ---: | --- | ---: | --- |
| 1 | GND | 17 | SDA |
| 2 | MCP-B | 18 | SCL |
| 3 | MCN-B | 19 | RESET |
| 4 | GND | 20 | PWDN |
| 5 | MDP0 | 21 | XCLK |
| 6 | MDN0 | 22 | DOVDD 1.8 V or 2.8 V |
| 7 | GND | 23 | AVDD 2.8 V |
| 8 | MDP1 | 24 | AF-VDD |
| 9 | MDN1 | 25 | DVDD 1.2 V |
| 10 | GND | 26 | GND |
| 11 | MDP2 |  |  |
| 12 | MDN2 |  |  |
| 13 | GND |  |  |
| 14 | MDP3 |  |  |
| 15 | MDN3 |  |  |
| 16 | GND |  |  |

`MCP-B/MCN-B` form the MIPI clock pair. `MDP0` through `MDP3` and `MDN0` through `MDN3` form the four MIPI data pairs.
