# About

JiuDing Docs is a collection of tutorials and guides maintained jointly by the JiuDing team and the community, providing support for JiuDing single-board computers and their peripheral products.

# Encountering Issues

If you encounter any problems while using this documentation, please submit an issue on GitHub. We will respond as soon as possible.

# Join the Community

- Official Website: [9tripod Website](http://www.9tripod.com) - JiuDing official website
- Official Forum: [9tripod Forum](http://bbs.9tripod.com) - Technical support channel

Note:

We do not recommend discussing technical issues or seeking help within closed software (e.g., WeChat groups / QQ groups and other apps whose content cannot be indexed by search engines). Please keep technical discussions in open venues such as the official forum or GitHub issues. WeChat / QQ groups are primarily for socializing and quickly connecting with like-minded friends.

# Contributing

We warmly welcome everyone to report issues, contribute patches, add content, and showcase your work to JiuDing Docs.
