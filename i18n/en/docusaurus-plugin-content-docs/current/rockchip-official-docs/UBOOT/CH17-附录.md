# Appendix

## Download Links

### rkbin

- RK internal engineers: Log in to gerrit and search for the repository: "rk/rkbin"

- External engineers (choose one of the following):
  - Download the complete SDK released by RK
  - Download from GitHub: https://github.com/rockchip-linux/rkbin

### GCC

- RK internal engineers: Search for the repository on gerrit: "gcc-linaro-6.3.1"
- External engineers: Download the complete SDK released by RK or download from the Linaro official website

## Glossary

- U-Boot: [Universal Boot Loader](https://en.wikipedia.org/wiki/Das_U-Boot)
- AOSP: [Android Open-Source Project](https://en.wikipedia.org/wiki/Android_(operating_system)#Open-source_community)
- AVB: Android Verified Boot
- DTB: [Device Tree Binary](https://en.wikipedia.org/wiki/Device_tree)
- DTS: [Device Tree Source](https://en.wikipedia.org/wiki/Device_tree)
- Fastboot: [Originally a firmware update method for Android, now widely used in the embedded field](https://en.wikipedia.org/wiki/Android_software_development#Fastboot)
- GPT: [GUID Partition Table](https://en.wikipedia.org/wiki/Universally_unique_identifier)
- MMC: [Multi Media Card](https://en.wikipedia.org/wiki/MultiMediaCard), including: eMMC, SD cards, etc.
- SPL: Secondary Program Loader
- TPL: Tertiary Program Loader
- DTB: Noun, Device Tree Blob
- DTB: Noun, Device Tree Blob used for overlay
- DTC: Noun, Device Tree Compiler
- DTO: Verb, Device Tree Overlay operation
- DTS: Noun, Device Tree Source file
- FDT: Noun, Flattened Device Tree
