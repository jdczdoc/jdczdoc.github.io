# Android User Guide

## Command Terminal

Connect the debug UART and boot Android to access the Android console.

## Audio and Video Playback

Place media files on TF card, USB disk, or internal storage and open them with Android applications.

## Wi-Fi and Bluetooth

Enable Wi-Fi or Bluetooth in Android settings and connect to wireless networks or Bluetooth devices.

## USB Mouse and Keyboard

Connect a USB mouse or keyboard to a USB HOST port to operate Android.

## TF Card and USB Disk

Storage devices are usually mounted under `/storage/`.

## Camera

Connect a supported camera and open the camera application for preview, photo capture, or recording.

## Ethernet

Connect an Ethernet cable to the network port to access wired network.

## HDMI Display

HDMI output can mirror display and audio to an external monitor.

## Power and Sleep

The board powers on after 12V input is connected. The power key can be used for shutdown, sleep, and wake-up depending on firmware behavior.
