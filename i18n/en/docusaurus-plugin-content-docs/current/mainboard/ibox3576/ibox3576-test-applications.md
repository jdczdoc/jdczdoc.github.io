# Test Applications

The Android test application is used for hardware verification during development and production.

## LCD Test

Switch solid colors to check the LCD.

## Touch Test

Draw lines to verify touch operation.

## LED Test

Turn LEDs on or off from the test UI.

## Buzzer Test

Press and hold the test button to enable the buzzer.

## Backlight Test

Adjust brightness and verify backlight behavior.

## Key Test

Press hardware keys and check key events.

## Audio Test

Play a test sound to verify audio output.

## Camera Test

Start preview after connecting a supported camera.

## Network Test

Verify Wi-Fi or Ethernet connection.

## Serial Port Test

Short TXD and RXD to check loopback.

## Storage Test

Insert TF card or USB disk and check storage information.
