# Hardware Resources

| 【5】 | USB2.0 | USB2.0 interface |
| 【6】 | USB3.0 | USB3.0 interface |
| 【7】 | Ethernet 1 | Gigabit Ethernet Interface, RGMII interface |
| 【8】 | Ethernet 0 | Gigabit Ethernet Interface, RGMII interface |
| 【9】 | WIFI/BT | WIFI/Bluetooth module |
| 【10】 | USB2.0 | 4P1.25mm socket USB2.0 interface |
| 【11】 | USB2.0 | 4P1.25mm socket USB2.0 interface |
| 【12】 | RTC | RTC battery interface |
| 【13】 | LVDS | LVDS screen interface |
| 【14】 | MIC | Microphone, recording input |
| 【15】 | Headphone holder | Headphone and headset interface |
| 【16】 | boot button | Download button for burning firmware |
| 【17】 | MIPI DSI | MIPI screen interface |
| 【18】 | UART8 | 4P2.0mmPH socket, UART8, TTL level interface |
| 【19】 | I2C0 | 4P2.0mmPH socket, I2C0, I2C interface |

| 【24】 | LCD Power | LCD screen backlight Power, 6P2.0mmPH base |
| 【25】 | trumpet | 2×15W two-channel speaker interface, 4PIN 2.0mm horizontal PH socket |
| 【26】 | button | Reset and Power button |
| 【27】 | Button interface | Button external interface, 6P1.25mm socket |
| 【28】 | battery holder | 8P1.25mm seat |
| 【29】 | Fan interface | 12V fan interface |
| 【30】 | Power interface | 4P2.0mmPH socket for external power supply |
