# Configuration List

## Standard Hardware List

- One X3588S mini ITX mainboard
- One 12V/2A power adapter
- One Type-C data cable
- One USB-to-serial adapter board
- Cloud-disk resource link, obtained through customer service

## Optional Hardware List

- Speaker
- 7-inch 1024 x 600 capacitive-touch MIPI LCD module
- 10.1-inch 1280 x 800 EDP LCD module
- 13MP camera module
- USB camera
- Mini ITX case
