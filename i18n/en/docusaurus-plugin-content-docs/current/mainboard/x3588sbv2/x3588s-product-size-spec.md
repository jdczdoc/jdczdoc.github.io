# Size and Specifications

## Product Size

The X3588S mini ITX board uses the standard Mini-ITX size. The specification table lists 17cm x 17cm, compatible with common ITX computer cases.

![X3588S mini ITX product size drawing](./x3588s-product-size.png)

## Specifications

| Item | Parameter |
| --- | --- |
| SoC | Rockchip RK3588S |
| CPU | 64-bit octa-core CPU: 4x Cortex-A76 + 4x Cortex-A55, 8nm process, up to 2.4GHz |
| GPU | ARM Mali-G610 MP4 quad-core GPU, OpenGL ES3.2 / OpenCL 2.2 / Vulkan 1.1, 450 GFLOPS |
| NPU | Up to 6TOPS NPU, INT4/INT8/INT16 mixed precision, model conversion for TensorFlow/MXNet/PyTorch/Caffe frameworks |
| ISP | Integrated 48MP ISP with HDR and 3DNR |
| Video codec | 8K@60 H.265/VP9/AVS2 decode, 8K@30 H.264 AVC/MVC decode, 4K@60 AV1 decode, 8K@30 encode, H.265/H.264 support |
| Memory | 4GB/8GB/16GB 64-bit LPDDR4/LPDDR4X/LPDDR5, up to 32GB |
| Storage | 16GB/32GB/64GB/128GB eMMC |
| Storage expansion | 1 standard SATA3.0 interface for SATA3.0 SSD/HDD |
| Ethernet | Gigabit Ethernet |
| Wireless | 2.4G/5G dual-band Wi-Fi, 4G wireless module expansion supported |
| Video output | 1x HDMI2.1, 2x MIPI-DSI, 1x VGA |
| Audio | Speaker, phone output, HDMI audio output, Line-In, MIC input |
| USB | 1x USB3.0, 1x Type-C shared with VGA, 6x USB2.0, 3 USB2.0 ports via board headers |
| Power | DC12V input or standard ATX 12V input |
| Other interfaces | 2x RS485, 2x RS232, 2x UART, 1x Debug, 1x Fan |
| System | Android 12.0; Linux: Ubuntu, Debian 11, Buildroot |
| Size | 17cm x 17cm, standard Mini-ITX, compatible with common ITX cases |
| Weight | About 200g |
| Thermal | Heatsink mounting-hole distance: 75mm x 47mm |
| Power consumption | Standby about 1.08W, typical about 3.24W, maximum about 9.72W |
| Environment | Operating temperature -10°C to 70°C; storage temperature -20°C to 70°C; storage humidity 10% to 80% |
