# Package Contents

## Standard Items

- PICO2 development board
- Type-C data cable
- USB-to-UART adapter
- SDK, flashing tools, and documentation links

## Optional Items

- 4 Ω / 3 W speaker
- 8 GB or larger TF card
- GC2083 MIPI camera
- 2.0-inch 240×320 SPI TFT LCD

Before first boot, connect UART0 at 115200 8N1 and use a Type-C cable that supports USB data.
