# Product Introduction

PICO2 is a compact smart-vision development board based on the Allwinner V821 processor family. It targets battery doorbells, smart locks, access control terminals, network cameras, and lightweight AI vision products.

![PICO2 front view](./images/hardware/image1.png)

## Processing and Multimedia

- RISC-V application core up to 1.2 GHz.
- RISC-V auxiliary core up to 600 MHz for RTOS and AMP workloads.
- Integrated 16-bit DDR2, up to approximately 533 MHz.
- 128 MB onboard SPI NOR Flash.
- Smart video engine supporting up to 2M@25fps H.265 encoding and 2M@60fps JPEG processing.
- Integrated ISP with 2D/3D noise reduction, HDR, and edge enhancement.
- DVP and 2-lane MIPI CSI camera input.
- Serial RGB, MCU, and DBI display output.
