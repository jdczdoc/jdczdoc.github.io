# Android User Guide

## Command Terminal

Connect the debug UART and boot Android. The serial terminal can be used to access the Android console.

## Audio and Video Playback

Place audio, video, or image files on TF card, USB disk, or internal storage and open them with Android applications.

## Wi-Fi and Bluetooth

Enable Wi-Fi or Bluetooth in Android settings, then connect to wireless networks or pair with Bluetooth devices.

## USB Mouse and Keyboard

Connect a USB mouse or keyboard to a USB HOST port to operate Android.

## TF Card and USB Disk

Storage devices are usually mounted under `/storage/`.

## Screen Rotation

Screen rotation depends on sensor configuration and application support.

## Camera

Connect a supported camera module and open the camera application for preview, capture, or recording.

## Ethernet

Connect an Ethernet cable to the RJ45 port. Android can access the network after link-up.

## HDMI Display

HDMI can output display and audio depending on the display configuration.

## Power and Sleep

The power key can be used for sleep, wake-up, or shutdown according to firmware behavior.
