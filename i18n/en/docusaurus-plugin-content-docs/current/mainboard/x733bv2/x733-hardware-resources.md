# Hardware Resources

## Board specifications

![X733BV2 dimensions](./x733-board-dimensions.png)

| Item | Specification |
|---|---|
| Board | X733BV2 |
| Processor | Allwinner A733, Cortex-A76 + Cortex-A55 |
| Frequency | Up to approximately 2 GHz |
| Memory | 2 GB / 4 GB / 8 GB |
| eMMC | 4 GB / 8 GB / 16 GB / 32 GB / 64 GB |
| PMIC | AXP318W |
| Power input | 12 V DC, 3 A recommended; battery input also available |
| Dimensions | 150 mm × 102 mm × 1.6 mm |
| Operating temperature | 0 to 70 °C |
| Storage temperature | -10 to 50 °C |

## Interface summary

| Category | Resources |
|---|---|
| Display | HDMI OUT ×1, MIPI DSI ×1, eDP ×1 |
| Video input | HDMI IN ×1, converted to MIPI CSI by LT6911C |
| Camera | 4-lane MIPI CSI ×1 |
| Touch | I2C, interrupt and reset signals on display connectors |
| Network | RTL8211F Gigabit Ethernet ×1 |
| USB | USB 3.0 Host ×1, USB 2.0 Host ×4, Type-C OTG ×1 |
| Storage | Onboard eMMC, TF card, M.2 expansion |
| Audio | Microphone ×2, stereo speaker outputs, headphone output |
| Debug | UART0 console, BOOT/RST/PWRON keys |
| Other | Battery, 12 V fan, flash LED and external key connectors |
| Wireless | AW869A Wi-Fi 6 and Bluetooth 5.2 |
