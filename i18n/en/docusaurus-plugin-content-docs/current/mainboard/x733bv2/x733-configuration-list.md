# Configuration List

| Category | Options / notes |
|---|---|
| Board | X733BV2 |
| Source board | `x733bv2` |
| Processor | Allwinner A733 |
| CPU architecture | Octa-core Cortex-A76 + Cortex-A55 |
| Memory | 2 GB / 4 GB / 8 GB |
| eMMC | 4 GB / 8 GB / 16 GB / 32 GB / 64 GB |
| PMIC | AXP318W |
| Input | 12 V DC, 3 A recommended; battery input supported |
| Wireless | AW869A Wi-Fi 6 / Bluetooth 5.2 |
| Ethernet | RTL8211F Gigabit Ethernet |
| Video output | HDMI OUT, MIPI DSI and eDP |
| Video input | HDMI IN converted to MIPI CSI by LT6911C |
| Storage expansion | TF card and M.2 |
| OS | Android 13; use the version included with the actual SDK |

## Standard kit

- X733BV2 development board
- 12 V power adapter
- Type-C data cable
- USB-to-UART adapter
- SDK, firmware and flashing tools

## Optional accessories

- TF card and M.2 storage device
- MIPI DSI/eDP panel with touch
- MIPI CSI camera
- Microphones, speakers and headphones
- Battery pack with matching temperature-sense wiring
- 12 V fan and heatsink
