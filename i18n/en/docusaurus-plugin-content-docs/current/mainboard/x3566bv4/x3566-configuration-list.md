# Configuration List

## Standard Hardware List

- One X3566 development board, with 7-inch 1024 x 600 capacitive-touch MIPI LCD module.
- One 12V/2A power adapter.
- One Micro USB data cable.
- One USB-to-UART adapter board.
- Cloud-disk resource link, available through the official WIKI.

## Optional Hardware List

- One speaker.
- One 8GB TF card.
- One 10.1-inch 1280 x 800 LVDS LCD module.
- One 8MP camera module.
- One USB camera.
