# Configuration List

## Standard Hardware List

- One ibox3568 mainboard.
- Network-disk resource link, available from the official BBS or customer service.

## Optional Hardware List

- One 7-inch 1024 x 600 capacitive-touch MIPI LCD module.
- One 10.1-inch 1280 x 800 capacitive-touch MIPI LCD module.
- One 12V / 2A power adapter.
- One Micro USB data cable.
- One USB-to-UART adapter board.
- One speaker.
- One 8GB TF card.
- One 10.1-inch 1280 x 800 LVDS LCD module.
- One 8MP OV5695 Camera.
- One USB Camera.
