# Configuration List

## Standard Hardware List

- One X6818 development board.
- 7-inch TFT LCD module, supporting RGB or MIPI interface.
- 5V power adapter.
- USB data cable.
- Serial cable.
- Cloud-disk resources and official documentation link.

## Optional Hardware List

- 4.3-inch, 5-inch, or 7-inch LCD panel.
- LVDS, MIPI, or RGB panel.
- Camera module.
- USB Wi-Fi/BT module.
- USB 3G module or PCIe 3G/4G module.
- TF card.
- Speaker.
- GPS / GPRS module.

## Development Resource List

The package usually includes hardware manual, Android platform user manual, Linux platform user manual, schematic, PCB-related materials, system images, source package, flashing tools, serial tools, and common test applications.
