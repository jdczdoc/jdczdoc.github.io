# Product Introduction

Pico PC RK3588S is a Raspberry Pi form-factor single-board computer based on Rockchip RK3588S. The board size is 85mm x 56mm. It provides Android 12, Linux, Ubuntu, Debian, and Buildroot resources for edge computing, multimedia, AI inference, display control, networking, industrial control, and general embedded development.

![Pico PC RK3588S board photo](./pico-pc-rk3588s-board-photo.png)

## Feature Highlights

- Quad-core ARM Cortex-A76 + quad-core Cortex-A55, up to 2.4GHz.
- Standard 4GB or 8GB LPDDR4 / LPDDR4X; other configurations can be ordered.
- Pluggable 16GB / 32GB eMMC.
- Two USB HOST 2.0 ports, two USB HOST 3.0 ports, one full-feature Type-C port, and one Type-C power input.
- Two 3.3V TTL UART ports, one of which is the default debug UART.
- One TF-card interface, one reset key, one power key, and one forced-upgrade key.
- One Micro HDMI output, one DSI display connector, and one CSI camera input.
- Headphone output and capacitive touch support.
- On-board high-speed dual-band Wi-Fi / Bluetooth module.
- RTC time retention, Gigabit Ethernet, and multiple GPIO expansion pins.
