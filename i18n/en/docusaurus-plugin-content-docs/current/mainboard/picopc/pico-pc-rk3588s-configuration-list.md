# Configuration List

## Standard Hardware List

- One Pico PC RK3588S board.
- 5V Type-C power adapter or power cable.
- Android / Linux / Ubuntu / Debian / Buildroot image resources.
- User manuals, flashing tools, driver tools, and source resources.

## Optional Hardware List

- 7-inch MIPI panel (1024 x 600).
- MIPI CSI camera.
- TF card.
- USB mouse, keyboard, and USB disk.
- Heatsink.
- USB camera.
- 4G module or other expansion module.
- Debug UART cable.
