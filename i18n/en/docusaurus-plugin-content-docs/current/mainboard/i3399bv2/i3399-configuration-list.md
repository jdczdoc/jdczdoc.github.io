# Configuration List

## Standard Hardware List

- One I3399 mainboard
- One 12V/2A power adapter
- One Type-C data cable
- One serial cable
- One USB-to-serial adapter board
- Cloud-disk resource link, available through the official WIKI

## Optional Hardware List

- Speaker
- 7-inch 1024*600 capacitive-touch MIPI LCD module
- 10.1-inch 1280*800 MIPI LCD module
- OV13850 13MP camera module
- PCIe 4G full-network module
- USB camera
