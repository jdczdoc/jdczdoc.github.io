X8385 supports Android / Linux operating systems. The driver support table from the hardware manual is organized below.

## Notes

- In the Linux 4.4 + Android 9.0 column, items marked with “✓” are supported.
- In the Linux 4.4 + Qt 5.9 column, most items are marked as coming soon.
- The Android user manual also refers to the X8385 Android 13 source package and Android 13 flashing flow. The actual system version should follow the SDK and firmware package released in the network-disk resources.
