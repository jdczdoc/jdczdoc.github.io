# Configuration List

## Standard Hardware List

- X8385CV1 core board.
- X8385 baseboard.
- 7-inch MIPI LCD board.
- 12V power adapter.
- Android / Linux system images and source resources.
- Flashing tools, driver tools, and user manuals.

## Optional Hardware List

- MIPI Camera.
- USB Camera.
- TF card.
- USB mouse, keyboard, and USB disk.
- Debug UART cable.
- Speaker, headphone, microphone, and other audio peripherals.
- Other GPIO / I2C / SPI / UART expansion peripherals.
