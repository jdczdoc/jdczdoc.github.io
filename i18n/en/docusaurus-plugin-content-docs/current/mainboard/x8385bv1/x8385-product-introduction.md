# Product Introduction

The X8385 development board is a high-performance AIoT development board based on the MediaTek MT8385 / i500 platform. It is developed, manufactured, and sold by Shenzhen 9Tripod Innovation Technology Co., Ltd. The board consists of the X8385CV1 stamp-hole core board, baseboard, and LCD board. The core board uses a 10-layer PCB design, while the baseboard provides 100M Ethernet, CSI, DSI, UART, SPI, Micro USB, USB 2.0, SDIO, I2S, I2C, TF card, HDMI, and other interfaces. The default display is a 7-inch MIPI LCD panel.

X8385 targets AIoT, AI, industrial control, power, communications, medical, media, security, automotive, finance, consumer electronics, handheld devices, and teaching instruments.

## Feature Highlights

- CPU: quad-core ARM Cortex-A73 + quad-core ARM Cortex-A53.
- Clock: A73 quad-core 2GHz + A53 quad-core 2GHz.
- Memory: 2GB / 4GB / 8GB LPDDR4, 2GB standard.
- Flash: multiple eMMC capacity options, 16GB standard.
- Three USB HOST 2.0 ports and one Micro USB OTG port; OTG is shared with USB HOST 2.0.
- Five TTL UART interfaces, one of which is the debug UART.
- One TF-card interface, one reset key, one power key, and four independent keys.
- External speaker, MIC input, headphone output, stepless backlight adjustment, and capacitive touch.
- On-board 2.4G / 5G dual-band Wi-Fi, Bluetooth, RTC, and 100M Ethernet.
- MIPI Camera, MIPI display, USB mouse, and USB keyboard support.
