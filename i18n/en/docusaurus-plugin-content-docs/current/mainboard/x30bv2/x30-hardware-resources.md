# Hardware Resources

This page summarizes connector locations and hardware resources for the X30 development board. For design notes, see [Hardware Design](./x30-hardware-design). For the complete 144-pin definition, see [Core Board Pin Definition](./x30-pin-definition).

## Hardware Interface List

| No. | Name | Description |
| --- | --- | --- |
| 【1】 | CPU | PX30，A35,4*1.3GHz |
| 【2】 | 内存 | 1GB DDR3 |
| 【3】 | eMMC | 8GB |
| 【4】 | DSI | MIPI或LVDS液晶屏接口 |
| 【5】 | RGB | RGB液晶屏接口 |
| 【6】 | IR | 红外一体化接收头 |
| 【7】 | BEEP | 蜂鸣器 |
| 【8】 | RTC | RTC电池座，2.0接口 |
| 【9】 | LED灯 | 四路可编程LED灯 |
| 【10】 | UART3 | 串口3，TTL电平 |
| 【11】 | UART2_M1 | 串口2，TTL电平，默认调试串口。 |
| 【12】 | MIC | 板载麦克风输入 |
| 【13】 | 耳机座 | 耳机输出 |
| 【14】 | 喇叭接口 | 外置扬声器接口 |
| 【15】 | CSI | MIPI摄像头接口 |
| 【16】 | 百兆网口 | 百兆以太网接口 |
| 【17】 | USB HOST3 | USB HOST2.0接口 |
| 【18】 | USB HOST2 | USB HOST2.0接口 |
| 【19】 | USB HOST1 | USB HOST2.0接口 |
| 【20】 | OTG | 程序下载接口，OTG功能时可做HOST功能 |
| 【21】 | DC座 | 12V DC电源输入 |
| 【22】 | ANT | WIFI/BT天线接口 |
| 【23】 | K1 | 独立按键 |
| 【24】 | K2 | 独立按键 |
| 【25】 | K3 | 独立按键 |
| 【26】 | K4 | 独立按键 |
| 【27】 | POWER | 电源按键 |
| 【28】 | RESET | 复位按键 |
| 【29】 | UART2_M0 | 串口2，TTL电平，和TF卡复用，可以通过程序配置成调试串口，默认使用UART2_M1作为调试串口 |
| 【30】 | TF卡 | TF卡座 |
| 【31】 | SIM卡槽 | 3G、4G手机卡槽 |
| 【32】 | PCIE接口 | 接3G、4G模块的PCIE接口 |
| 【33】 | WIFI/BT | AP6212 WIFI/BT二合一模块 |
