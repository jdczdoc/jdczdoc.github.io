# Configuration List

## Standard Hardware List

- One X30 development board with 7-inch 1024 x 600 capacitive-touch MIPI LCD module.
- One 12V/2A power adapter.
- One Micro USB data cable.
- One serial cable.
- Cloud-disk resource link, available through the official WIKI.

## Optional Hardware List

- 7-inch RGB panel.
- 10.1-inch LVDS panel.
- Camera module.
- USB 3G/4G module.
- TF card.
- Speaker.
