# Configuration List

## Standard Hardware List

- One X3399 development board with 7-inch 1024 x 600 capacitive-touch MIPI LCD module.
- One 12V / 2A power adapter.
- One Type-C data cable.
- One serial cable.
- Network-disk resource link, available from the official Wiki.

## Optional Hardware List

- One speaker.
- One 8GB TF card.
- One 7.9-inch 2K MIPI LCD module.
- One 7.9-inch 2K EDP LCD module.
- One 10.1-inch 1280 x 800 MIPI LCD module.
- One 10.1-inch 2K EDP LCD module.
- One 13MP OV13850 Camera.
- One 5MP OV5645 Camera.
- One HDMI cable compatible with x210, x4412, x3288, and x3399.
- One USB-to-UART cable.
- One USB 3G dongle.
- One PCIe 3G module.
- One PCIe 4G full-network module.
- One TVIN module.
- One USB Wi-Fi / Bluetooth combo module.
- One GPS module.
- One GPRS module.
- One USB Camera.
