# Hardware Resources

The X3399V4 baseboard provides rich peripherals, including Gigabit Ethernet, CSI, DSI, HDMI, EDP, Type-C, USB 3.0, USB 2.0, optical audio output, IR receiver, dual CSI, PCIe, SIM card, speaker, headphone, TF card, RTC, buzzer, and Wi-Fi/BT resources.

![X3399V4 board interface map](./x3399v4-board-interface-map.png)
