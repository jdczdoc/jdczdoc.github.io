# Configuration List

## Standard Hardware List

- One X3568 mainboard set with a 7-inch 1024×600 capacitive-touch MIPI LCD module;
- One 12V / 2A power adapter;
- One Micro USB data cable;
- One USB-to-UART adapter board;
- Cloud-drive resource link, available from the official BBS or customer service.

## Optional Hardware List

- One speaker;
- One 8GB TF card;
- One 10.1-inch 1280×800 LVDS LCD module;
- One 8MP OV5695 camera;
- One USB camera.
