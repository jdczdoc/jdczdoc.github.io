# Configuration List

## Standard Hardware List

- One X3128 development board set, including a 4-inch 480 x 800 capacitive touch LCD module.
- One 12V / 2A power adapter.
- One Micro USB cable.
- One serial cable.
- One serial debug board.
- Network-disk resource link.

## Optional Hardware List

- One 8GB TF card.
- One high-quality HDMI cable.
- One USB-to-serial cable.
- One GPS module.
- One USB camera.
