# Configuration List

## Standard Hardware List

- X3288 mainboard kit with 7-inch 1024 × 600 capacitive-touch LCD module.
- 12 V / 2 A power adapter.
- USB data cable.
- Serial cable.
- Serial debug board.
- Network-disk data link, available after purchase through customer service.

## Optional Hardware List

- 8 GB TF card.
- OV13850 13 MP camera module.
- HDMI cable compatible with X210 / X4412 / X3288.
- USB-to-serial cable.
- USB 3G modem.
- TVIN module.
- USB Wi-Fi / Bluetooth combo module.
- VGA module.
- GPS module.
- USB camera.
