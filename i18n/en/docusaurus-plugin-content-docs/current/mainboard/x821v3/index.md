# X821 Main Board

The X821V30 is an AI-agent main board built around the Allwinner V821 dual-RISC-V SoC. It integrates 64MB DDR2, 128MB flash, 2.4GHz Wi-Fi, BLE, audio, MIPI CSI, SPI LCD, and touch interfaces. The supplied software platform is Linux 5.4 with Tina Linux 5.0.
