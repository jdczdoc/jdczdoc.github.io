# Configuration List

## Standard Package

- One X821V30 main board.
- Associated cloud-drive materials supplied by the vendor.

## Optional Accessories

| Accessory | Suggested specification / quantity |
| --- | --- |
| TF card | 8GB or larger, one |
| Battery | Single-cell 3.7V lithium battery, one |
| USB cable | Type-C data cable, one |
| Speaker | 8Ω/3W, one |
| Microphones | Two assemblies |
| LED assembly | One |
| LCD | 2.0-inch, 240×320, one |
| Camera | One sensor matching the current SDK configuration |

For cameras, LCDs, and touch panels, verify voltage levels, pin order, driver model, and device-tree configuration. Connector appearance alone is not sufficient for compatibility.
