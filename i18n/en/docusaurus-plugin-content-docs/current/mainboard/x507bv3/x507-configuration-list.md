# Package Contents

## Standard Items

- One X507 development board; the manual describes a kit with a 7-inch 1024×600 capacitive-touch RGB panel.
- One 12V/2A power adapter.
- One Micro USB data cable.
- One serial cable.
- Download link or official WIKI documentation.

## Optional Items

- External speaker.
- 8GB TF card.
- 10.1-inch 1280×800 LVDS panel.
- 2-megapixel camera.
- USB-to-UART cable.
- USB camera.

## Incoming Inspection

Before selecting an SDK or device tree, check the carrier-board revision, core-module revision, RAM/eMMC capacity, wireless-module model, panel interface, and adapter specification.
