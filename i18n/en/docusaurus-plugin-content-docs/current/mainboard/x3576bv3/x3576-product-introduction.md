# Product Introduction

X3576BV3 is an eight-core Rockchip RK3576 development board supporting Android 14 and Linux. Its HDMI input and output, MIPI display and camera interfaces suit edge computing, smart terminals and multimedia applications.

| Item | Specification |
| --- | --- |
| Processor | RK3576, 4× Cortex-A72 + 4× Cortex-A53, 1.8 GHz in the documented configuration |
| Memory | 2 / 4 / 8 GB |
| Storage | 4 / 8 / 16 / 32 / 64 GB eMMC and TF card support |
| Power | 12 V DC, recommended 12 V / 3 A adapter, RK806-S PMIC |
| Display and capture | One MIPI DSI up to 2K@60 Hz, HDMI OUT, HDMI IN and two MIPI CSI inputs |
| Networking | RTL8211F Gigabit Ethernet, VS2275P Wi-Fi 6 / Bluetooth, and PCIe expansion with SIM socket |
| USB | One USB 3.0 Host, five USB 2.0 Host ports and Type-C OTG |
| Expansion | TTL debug and expansion UARTs, RS232, GPIO, ADC, IR, touch and fan |
| Audio | Headphones, LINE IN, onboard microphone and two 0.5 W speaker outputs |

Memory, storage and peripheral drivers depend on the fitted board and firmware version.
