# Package Contents

## Standard Hardware

- One X8390/X8370 development board.
- One power adapter.
- One Type-C cable.
- One USB-to-TTL serial adapter.
- Access to the supporting documentation package through the sales or project-delivery channel.

The electrical specification recommends 12V / 3A, while the original package list mentions a 12V / 2A adapter. Use the current BOM and load requirement for the delivered board.

## Optional Hardware

- External speaker.
- 8GB or larger TF card.
- 7-inch 1024 × 600 capacitive-touch MIPI display module.
- Wi-Fi / Bluetooth module.
- MIPI camera module.
- Lithium battery and matching cable.
