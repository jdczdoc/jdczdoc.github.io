# Hardware Resources

This page summarizes the connector locations and hardware resources of the MT8788 girlfriend-machine mainboard. For detailed pin definitions, see [Connector Definition](./mt8788-girlfriend-machine-connector-definition).

![MT8788 girlfriend-machine mainboard interface map](./mt8788-board-interface-map.png)

## Hardware Interface List

| No. | Name | Description |
| --- | --- | --- |
| 【1】 | KEY interface | External power key |
| 【2】 | Headphone interface | External headphone |
| 【3】 | USB 2.0 | Standard Type-A USB 2.0 interface |
| 【4】 | USB 2.0 | Standard Type-A USB 2.0 interface |
| 【5】 | HDMI IN | Standard Type-C HDMI input interface |
| 【6】 | Type-C interface | Standard Type-C USB 2.0 interface |
| 【7】 | DC 12V input接口 | NC by default; powered internally through interface 8 |
| 【8】 | DC 12V wafer座 | 12V DC power input |
| 【9】 | RS232 / I2C interface | RS232 UART or I2C interface for reading battery level |
| 【10】 | LVDS interface | External dual-channel LVDS display interface, supports standard 1080p LCD panels in various sizes |
| 【11】 | CSI interface | For external MIPI camera |
| 【12】 | Light / NFC interface | For external light-sensing or NFC device |
| 【13】 | UART1 | Standard UART interface |
| 【14】 | LED connector | Dual-color LED indicator connector |
| 【15】 | RTC connector | External coin-cell battery for RTC time retention after power loss |
| 【16】 | IR receiver connector | External integrated IR receiver |
| 【17】 | Backlight | Screen backlight connector |
| 【18】 | MIC x2 | Dual MIC connectors |
| 【19】 | MIC x2 | Dual MIC connectors |
| 【20】 | Speaker | Stereo 3~15W speaker interface with integrated EQ |
| 【21】 | USB 2.0 wafer connector | Internal standard USB 2.0 wafer connector |
| 【22】 | USB 2.0 wafer connector | Internal standard USB 2.0 wafer connector |
| 【23】 | USB 2.0 wafer connector | Internal standard USB 2.0 wafer connector |
| 【24】 | USB 2.0 wafer connector | Internal standard USB 2.0 wafer connector |
