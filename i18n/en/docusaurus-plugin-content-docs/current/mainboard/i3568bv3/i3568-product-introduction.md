# Product Introduction

The I3568BV3 combines an X3568CV4 core board with a carrier. It uses a quad-core RK3568 or RK3568B2 Cortex-A55 processor running at up to 2 GHz. The board supports Android 11 and Linux 4.19 for display terminals, industrial control and multimedia applications.

| Item | Specification |
| --- | --- |
| Memory | Standard 4 GB DDR4, LPDDR4/LPDDR4X configurations, up to 8 GB |
| Storage | Standard 16 GB eMMC, with TF and SATA expansion |
| Power | 12 V DC board input, RK809 PMU on the core board |
| Display | HDMI 2.0, DSI/LVDS, LVDS and eDP, with capacitive touch support |
| Camera | 30-pin MIPI CSI connector |
| USB | Two USB 3.0 Host ports, three USB 2.0 Host ports and Micro USB OTG |
| Networking | One Gigabit Ethernet port and dual-band 2.4/5 GHz SDIO Wi-Fi/Bluetooth |
| Expansion | UART2 debug, UART3/4/9, CAN, I2C, ADC and GPIO |
| Audio and controls | Headphones, speaker, onboard microphone, RTC, IR and external keys |

Memory, storage, wireless module and system depend on the delivered configuration. Linux images may use Buildroot, Debian or Ubuntu. Panels, cameras and other peripherals require matching firmware drivers.
