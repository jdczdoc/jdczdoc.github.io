# Android User Guide

The series ships with or supports Android 12.0. Menu names depend on the firmware version and interface customization.

## Connect to Wi-Fi

1. Open Settings.
2. Turn on Wi-Fi.
3. Select the network and enter its password.

## Wi-Fi Hotspot

Turn on Wi-Fi hotspot in Settings and set a password. Other devices can then find and join the hotspot.

## Pair Bluetooth Devices

1. Open Settings and select **Connected devices**.
2. Select **Pair new device** to discover Bluetooth devices.
3. Select the target device and confirm pairing.

## Ethernet

1. In Settings, open **Network & internet**.
2. Open **Ethernet**.
3. Connect the network cable and check the IP address and IP mode.

## Storage Information

Open **Storage** in Settings to check usage. System partitions and preinstalled applications affect the available capacity.

## Antennas

Attach antennas to the corresponding connectors before using Wi-Fi or Bluetooth. Coverage depends on the antenna and installation environment.

## Live Production Software

The live production APK is listed as `Guide_Station_release_vx.x.x.apk`. Check the delivered firmware for availability and the installed version.
