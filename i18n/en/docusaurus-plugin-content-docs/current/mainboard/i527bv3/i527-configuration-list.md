# Configuration List

| Category | Options / Notes |
|---|---|
| Board | I527BV3 |
| Source product | `i527bv3` |
| Core module | X527CV2, 200 castellated pins |
| SoC | T527/T527N/A527 family, according to the module BOM |
| Memory | 2 GB / 4 GB LPDDR4X |
| eMMC | 4/8/16/32/64 GB and other BOM options |
| Input | 12 V DC, 3 A recommended |
| Wireless | AW869A Wi-Fi 6 / Bluetooth 5.2 |
| Ethernet | RTL8211F Gigabit Ethernet |
| Video output | HDMI OUT, eDP, LVDS and MIPI DSI |
| Video input | HDMI IN through LT6911C to MIPI CSI |
| OS | Android 13/14 and Linux, depending on the SDK release |

Typical accessories include a 12 V adapter, Type-C cable, USB-to-UART adapter, display/touch module, camera, speakers, PCIe 4G module, M.2 storage and a 12 V fan.
