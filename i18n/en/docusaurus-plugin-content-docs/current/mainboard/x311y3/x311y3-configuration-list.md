# Configuration list

## Standard hardware

- One development board with a 7-inch 1024 × 600 capacitive-touch MIPI display.
- One 12 V/2 A adapter.
- One Type-C data cable.
- One USB-to-UART adapter.
- Cloud-download information through the official wiki.

## Optional hardware

- Speaker.
- 8 GB TF card.
- 10.1-inch 1280 × 800 LVDS display.
- 13-megapixel camera.
- USB camera.
