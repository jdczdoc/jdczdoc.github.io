# Hardware Resources

This page summarizes connector locations and hardware resources for the I3566 mainboard. For connector usage, see [Interface Details](./i3566-interface-details). For the complete 172-pin core-board definition, see [Core Board Pin Definition](./i3566-pin-definition). For PH connectors and expansion headers, see [Expansion Connector Definition](./i3566-expansion-connectors).

![I3566 mainboard interface map](./i3566-board-interface-map.png)

| --- | --- | --- |

| 【2】 | Wi-Fi | 6221A-SRC dual-band Wi-Fi module |
| 【3】 | UART2 | UART2, TTL-level interface, default debug UART |
| 【4】 | CIF | Parallel camera interface |
| 【5】 | RK3566核心模块 | I3566 core board |
| 【6】 | RTC | RTC battery holder, 3V supply |
| 【7】 | GPIO | GPIO expansion interface |
| 【8】 | RS485 | RS485 interface |
| 【9】 | RS232 | RS232 interface |
| 【10】 | UART6 | 3.3V TTL-level UART6 interface |
| 【11】 | UART0 | 1.8V TTL-level UART0 interface |
| 【12】 | 喇叭接口 | External dual-channel speaker |
| 【13】 | 麦克风接口 | External microphone input |
| 【14】 | 红外接收头 | HS0038 integrated IR receiver |
| 【15】 | 触摸屏接口 | 6-pin PH connector for external capacitive touch panel |
| 【16】 | 显示接口 | EDP interface |
