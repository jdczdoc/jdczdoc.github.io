# Configuration List

## Standard Hardware List

- One i6818 development board with 8-inch 1024 x 768 capacitive touchscreen.
- One 5V / 2A power adapter.
- One USB data cable.
- One serial adapter board.
- One serial extension cable.
- Development board resources downloaded from the network disk.

## Optional Hardware List

- 8G TF card.
- HDMI cable compatible with x210, x4412, x4418, and x6818.
- USB-to-UART extension cable.
- USB 3G modem.
- USB camera.

## Development Resource List

i6818 resources are provided through the network disk and include board source code, development environment setup documents, user manuals, step-by-step examples, core-board and baseboard schematics, component footprint libraries, flashing tools, and related materials.
