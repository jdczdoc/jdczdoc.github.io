# Core Board Pin Definitions

The following tables preserve all pins 1 through 200, signal names and remarks from source Table D-1. The package is a 200-pin castellated module. Verify direction and electrical properties against the schematic. Some source remarks disagree with the signal names, including MISO/MOSI for SPI2_MO/MI on pins 47/48, I2S2 for I2S1_LRCK on pin 59, and input for I2S2_DO on pin 150; do not use those remarks in place of schematic connectivity.

VSYS (pins 197 through 200) is the 4 V input and VSYS_S (pin 175) is the sense input. Use VIO18_PMU (173), VIO28_PMU (174) and VMCH_PMU (172) only as described in Hardware Architecture. Other core rails are generated by the onboard PMICs.
