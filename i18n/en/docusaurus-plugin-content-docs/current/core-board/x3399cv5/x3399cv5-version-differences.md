# Version Differences

Core BoardVersion Differences

| 版本Description | 修改Description | 修改目的 |
| --- | --- | --- |
| x3399cv2.1 | 第一次对外发布，默认使用两片LPDDR3，十层PCB走线 |  |
| x3399cv3 | 硬件封装优化，pin和x3399cv2.1完全兼容，默认使用两片LPDDR3，十层PCB走线 | 统一阻容封装 |
| x3399cv4 | DDR变更，由两片LPDDR3变更为两片LPDDR4； / PCB由十层调整到八层； / Core Board焊盘调小，增加焊盘间间距，提高焊接良率； / pin完全兼容x3399cv3 | 相对x3399cv3，通过变更DDR型号降低成本 |
| x3399cv5 | PCB上对称脚增加两个淘空孔，for 屏蔽罩定位； | 相对x3399cv4，优化了屏蔽罩固定方式 |
