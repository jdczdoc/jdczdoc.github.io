# Version Differences

Core BoardVersion Differences

| VersionDescription | ModifyDescription | Modification purpose |
| --- | --- | --- |
| x3399cv2.1 | Released for the first time, using two pieces of LPDDR3 by default and ten-layer PCB routing |  |
| x3399cv3 | Hardware packaging optimization, pin and x3399cv2.1 are fully compatible, using two LPDDR3 by default, ten-layer PCB routing | Unified resistance and capacitance packaging |
| x3399cv4 | DDR change, from two pieces of LPDDR3 to two pieces of LPDDR4; / PCB adjusted from ten layers to eight layers; / Core Board pads reduced, increasing spacing between pads, improving welding yield; / pin fully compatible with x3399cv3 | Compared with x3399cv3, the cost is reduced by changing the DDR model |
| x3399cv5 | Two hollow holes are added to the symmetrical feet on the PCB for positioning of the shield cover; | Compared with x3399cv4, the shielding cover fixing method is optimized. |
