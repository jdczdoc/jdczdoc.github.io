# Core board revisions

| Version | Changes | Purpose |
| --- | --- | --- |
| x30cv1 | Initial public release, two DDR3 devices by default |  |
| x30cv2 | Memory changed from DDR3 to LPDDR3 | 1 GB DDR3 devices discontinued; supports 2 GB or greater memory capacity |
| X30CV2001 | PX30, 144-pin 45 mm × 45 mm castellated core board, 2 GB RAM and 16 GB storage | Same model as X30CV2; internal revision using a commercial-grade CPU by default |
| X30CV2002 | PX30K, 144-pin 45 mm × 45 mm castellated core board, 2 GB RAM and 64 GB storage; custom module for Hangzhou Dongsheng requiring CPU, DDR and eMMC rated for -20°C to +85°C | Same model as X30CV2; compared with X30CV2001, uses the wide-temperature PX30K CPU and DDR/eMMC rated for -20°C to +85°C by default; Samsung or Kioxia eMMC is specified. |
