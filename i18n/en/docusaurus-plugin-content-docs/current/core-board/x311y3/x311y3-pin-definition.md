# SoC pin and net definitions

The source describes 286 mappings across U1A–U1N; the extracted tables contain **287 rows** with distinct section/ball pairs. All source rows are retained. Confirm this count discrepancy against the controlled pin-definition table.

:::caution

Appendix D power pins are inputs, references or decoupling connections; the core board supplies no external power. VDD_EE, VDD_A78, VDD_A55, VDD_GPU, VDD_NPU, VDD_DDR, VDD_2H2 and VDDQ are generated by onboard DC/DC converters and are not exposed.

:::

This appendix reproduces the core board pin definitions from the accompanying X311Y3 development board hardware manual. It covers 14 schematic sections, U1A–U1N, and 286 pin/network mappings. Section identifies the schematic partition, signal name identifies the SoC pin, and board connection records the design net or connection note. The BGA-ball identifiers follow the source and do not constitute a separately verified LGA-pad numbering table.
