# USB TO TTL Adapter Board

## Overview

The USB TO TTL adapter board is an industrial USB-to-TTL serial debugging tool provided by JiuDing. It is suitable for embedded development and debugging, MCU flashing, router configuration, PLC debugging, and similar tasks.

The product supports both 1.8V and 3.3V output levels and allows one-key switching through the onboard selector switch. It uses a standard GND, TXD, RXD, and VCC pin-header interface and supports direct connection through Dupont wires.
