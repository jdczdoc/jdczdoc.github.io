# USB TO TTL 串口调试板

## 产品概述

USB TO TTL 串口调试板是九鼎创展提供的工业级 USB 转 TTL 串口调试工具，适用于嵌入式开发调试、单片机烧录、路由器配置、PLC 调试等场景。

该产品支持 1.8V / 3.3V 双电压输出，可通过拨码开关一键切换，接口定义为标准 GND、TXD、RXD、VCC 排针接口，支持杜邦线直连。
