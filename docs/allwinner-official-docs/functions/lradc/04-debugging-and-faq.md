# LRADC 调试与常见问题

- 按下某键却上报相邻键：重新测量电压并扩大键间间隔。
- 长按重复异常：检查 input repeat 配置及驱动去抖时间。
- 偶发无键值：检查电阻网络、按键接触、ADC 输入电容和采样滤波。
- 所有键无响应：确认 `compatible` 与参考电压版本匹配，并检查节点状态。
- 中断次数增长但无事件：查看驱动滤波是否把当前电压判为无效区间。
## 通用定位顺序

1. 原理图与供电。
2. 最终 DTB 中的节点和 pinctrl。
3. 最终 `.config` 与 `.ko`。
4. probe、clock、reset、IRQ 日志。
5. 设备节点与 sysfs/debugfs。
6. 最小功能测试。
7. 压力、休眠和异常插拔测试。

不要通过关闭错误日志来判断问题已经解决。应找到第一个异常并验证其上下游依赖。
