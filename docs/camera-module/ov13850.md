# OV13850 摄像头模组

## 产品概述

OV13850 摄像头模组采用 OmniVision OV13850 彩色 CMOS 图像传感器，最高支持 4224 × 3136 分辨率输出。

## 主要参数

| 项目 | 参数 |
| --- | --- |
| 图像传感器 | OmniVision OV13850 |
| 传感器类型 | 彩色 CMOS，滚动快门 |
| 有效像素阵列 | 4224 × 3136 |
| 像素数量 | 约 1320 万像素 |
| 光学尺寸 | 1/3.06 英寸 |
| 像素尺寸 | 1.12 μm × 1.12 μm |
| 输出格式 | 10-bit RAW RGB |
| 数据接口 | MIPI CSI-2 |
| MIPI Lane | 支持 1 Lane、2 Lane 或 4 Lane |
| 单 Lane 最高速率 | 1200 Mbps |
| 控制接口 | SCCB |
| 输入时钟 | 6 MHz ～ 64 MHz |
| 最大帧率 | 4224 × 3136 @ 30 fps |
| 镜像与翻转 | 支持 |
| 裁剪与窗口 | 支持 |
| HDR | 支持 Alternate Row HDR |
| OTP | 内置 8 Kbit OTP |
| 温度传感器 | 内置 |

## 分辨率与帧率

| 输出模式 | 分辨率 | 最大帧率 | MIPI 配置 |
| --- | ---: | ---: | --- |
| 全分辨率 | 4224 × 3136 | 30 fps | 4 Lane，1200 Mbps/Lane |
| 16:9 模式 | 4224 × 2376 | 30 fps | 4 Lane，1200 Mbps/Lane |
| 2 × 2 Binning | 2112 × 1568 | 60 fps | 4 Lane，640 Mbps/Lane |
| EIS 1080P | 2112 × 1188 | 60 fps | 4 Lane，640 Mbps/Lane |
| EIS 720P | 1408 × 792 | 60 fps | 4 Lane，640 Mbps/Lane |
| 720P | 1280 × 720 | 120 fps | 4 Lane，640 Mbps/Lane |

## 电气参数

| 项目 | 参数 |
| --- | --- |
| 模拟电源 AVDD | 2.6 V ～ 3.0 V，典型值 2.8 V |
| 核心电源 DVDD | 1.14 V ～ 1.26 V，典型值 1.2 V |
| I/O 电源 DOVDD | 1.7 V ～ 3.0 V，典型值 1.8 V 或 2.8 V |
| 全分辨率工作功耗 | 约 199 mW，13MP @ 30 fps、ISP 关闭 |
| 待机功耗 | 约 300 μW |
| XSHUTDOWN 功耗 | 约 1 μW |

| --- | --- |
