# OV13855 摄像头模组

## 产品概述

RF13855-JD01 V1.0 摄像头模组采用 OmniVision OV13855 彩色 CMOS 图像传感器，提供 4 Lane MIPI CSI-2 图像输出，并通过 I2C 接口进行寄存器配置。

## 主要参数

| 项目 | 参数 |
| --- | --- |
| 模组型号 | RF13855-JD01 V1.0 |
| 图像传感器 | OmniVision OV13855 |
| 传感器类型 | 彩色 CMOS，滚动快门 |
| 像素数量 | 约 1300 万像素 |
| 常用输出分辨率 | 4224 × 3136 |
| 传感器有效像素阵列 | 4256 × 3168 |
| 光学尺寸 | 1/3.06 英寸 |
| 像素尺寸 | 1.12 μm × 1.12 μm |
| 像素技术 | PureCel Plus |
| 数据接口 | MIPI CSI-2 |
| MIPI 配置 | 4 Lane 数据通道，加 1 组时钟差分对 |
| 控制接口 | I2C，SDA / SCL |
| 自动对焦接口 | 提供 AF-VDD 供电引脚 |
| 相位对焦 | 支持 PDAF |
| 图像翻转 | 支持水平镜像和垂直翻转 |

## 分辨率与帧率

| 输出模式 | 分辨率 | 最大帧率 |
| --- | ---: | ---: |
| 全分辨率 | 4224 × 3136 | 30 fps |
| Full HD | 1920 × 1080 | 60 fps |
| HD | 1280 × 720 | 90 fps |

## 电气接口

| 电源或信号 | 参数 |
| --- | --- |
| DOVDD | 1.8 V 或 2.8 V |
| AVDD | 2.8 V |
| DVDD | 1.2 V |
| AF-VDD | 模组引出，具体电压取决于所配马达 |
| XCLK | 外部传感器时钟输入 |
| RESET | 硬件复位 |
| PWDN | 硬件掉电控制 |
| SDA / SCL | I2C 控制总线 |

## 26PIN 接口定义

| PIN | 信号 | PIN | 信号 |
| ---: | --- | ---: | --- |
| 1 | GND | 17 | SDA |
| 2 | MCP-B | 18 | SCL |
| 3 | MCN-B | 19 | RESET |
| 4 | GND | 20 | PWDN |
| 5 | MDP0 | 21 | XCLK |
| 6 | MDN0 | 22 | DOVDD 1.8 V 或 2.8 V |
| 7 | GND | 23 | AVDD 2.8 V |
| 8 | MDP1 | 24 | AF-VDD |
| 9 | MDN1 | 25 | DVDD 1.2 V |
| 10 | GND | 26 | GND |
| 11 | MDP2 |  |  |
| 12 | MDN2 |  |  |
| 13 | GND |  |  |
| 14 | MDP3 |  |  |
| 15 | MDN3 |  |  |
| 16 | GND |  |  |

其中，`MCP-B/MCN-B` 为 MIPI 时钟差分对，`MDP0～MDP3/MDN0～MDN3` 为 4 组 MIPI 数据差分对。
