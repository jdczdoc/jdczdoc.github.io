# IMX415 摄像头模组

## 产品概述

IMX415-98 IR-CUT 摄像头模组采用 Sony IMX415 图像传感器，支持 3840 × 2160 分辨率输出。

本页只保留摄像头模组和镜头参数，不包含开发板连接、驱动配置和测试命令。

## 模组参数

| 项目 | 参数 |
| --- | --- |
| 模组名称 | IMX415-98 IR-CUT Camera |
| 图像传感器 | Sony IMX415 |
| 有效像素 | 约 829 万像素 |
| 输出分辨率 | 3840 × 2160 |
| CMOS 光学尺寸 | 1/2.8 英寸 |
| 对角线尺寸 | 6.43 mm |
| 像素尺寸 | 1.45 μm × 1.45 μm |
| IR-CUT | 支持 |

## 镜头参数

| 项目 | 参数 |
| --- | --- |
| 焦距 | 3.95 mm |
| 光圈 | F2.0 |
| 对角视场角 | 98° |
| 水平视场角 | 84° |
| 垂直视场角 | 44° |
| 畸变 | 小于 1% |
