# 硬件设计

## 管脚描述

除引脚表中明确标注为不可用作GPIO的接口、电源引脚和系统地外，X733核心板的其他GPIO通常可复用为I2C、UART、SPI、I2S和PWM等功能。实际设计时，应结合核心板原理图和A733芯片规格书确认复用关系。

## GPIO电平

在设计底板时，需要确保外设芯片的IO电平与核心板对应IO电压域一致，否则可能损坏CPU或外设。

| VCC-PC | 1.8V | 电压域不可调 | 1.8V |
| VCC-PD | 1.8V | 电压域不可调 | 1.8V |
| VCC-LVDS | 1.8V | 电压域不可调 | 1.8V |
| VCC-PE | 1.8V | 电压域不可调 | 1.8V |

## 电源设计

根据X733引脚定义表：

- 17、18、19脚为 `PS`，用于5V主电源输入。
- 输入电流建议不低于 **3A**，纹波控制在 **100mV以内**。
- 主电源走线建议大于 **2mm**。
- 电源换层过孔建议不少于 **5个**。
- 20脚为 `DLDO5`，提供3.3V输出，可用于底板音频CODEC和PHY IO供电。
- 21脚为 `BLDO5`，提供1.8V输出，可用于底板音频CODEC和PHY IO供电。

> **原手册管脚号异常：** 硬件设计正文将159、160脚写成5V输入、161脚写成3.3V输出、156脚写成1.8V输出，但这些编号与X733的200PIN引脚表不一致，疑似沿用了其他核心板内容。X733底板设计应优先按17～21脚核对，并在投板前结合原理图再次确认。

## USB设计

硬件设计正文记录X733有2路USB2.0和2路USB3.0，而特性参数表记录3路USB2.0和2路USB3.0。引脚表中能看到USB0、USB1和USB2三组USB2.0差分信号，实际可用端口数量及复用关系应结合原理图确认。

PCB设计时需要注意：

- USB2.0理论带宽为480Mbps。
- USB3.0理论带宽最高为5Gbps。
- USB差分线需要等长布线。
- 差分阻抗为 **90Ω ±10%**。
- 差分线下方需要保持完整参考平面。

## HDMI设计

X733手册记录芯片集成一路HDMI OUT控制器并支持HDMI2.0。

- HDMI高速差分线需要等长布线。
- 差分阻抗为 **100Ω ±10%**。
- 阻抗或等长控制不当可能造成画面丢色、闪断或无显示。

## MIPI设计

X733资料中的接口数量存在差异：

- 特性参数表记录2路MIPI DSI和4 + 4 + 2 lane MIPI CSI。
- 硬件设计正文记录1路MIPI DSI和2路MIPI CSI。

实际接口实例数量、lane复用和电阻选配应以A733规格书、核心板原理图和实物配置为准。

MIPI高速差分线需要等长布线，差分阻抗为 **100Ω ±10%**。
