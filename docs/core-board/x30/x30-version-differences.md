# 核心板版本差异

| 版本描述 | 修改说明 | 修改目的 |
| --- | --- | --- |
| x30cv1 | 第一次对外发布，默认使用两片DDR3 |  |
| x30cv2 | 内存颗粒由DDR3变更为LPDDR3 | 单片1GB DDR3停产，用于支持2GB或更大容量内存 |
| X30CV2001 | PX30平台144PIN 45mm*45mm邮票孔核心板，容量2G&16G | 型号同x30cv2，内部版本，默认CPU使用商业级 |
| X30CV2002 | PX30K平台144PIN 45mm*45mm邮票孔核心板，容量2G&64G(杭州东胜定制模块，CPU、DDR、EMMC均需使用-20~85度宽温芯片) | 型号同x30cv2，相比x30cv2001，CPU变更为宽温版本PX30K，DDR和EMMC默认可支持到-20~85度，EMMC指定用三星或凯侠。 |
