# 硬件设计

## 管脚描述

X3576 核心板除电源、地以及明确标注为不可作为 GPIO 使用的引脚外，其余 GPIO 引脚均可根据芯片的引脚复用功能配置为其他接口，例如 GPIO、I2C、UART、SPI、I2S、PWM 等。

由于篇幅限制，本文不对所有 GPIO 引脚的复用功能逐一说明。实际设计时，请结合 **X3576 核心板原理图**以及 **RK3576 芯片规格书中的引脚复用说明**进行确认。

### GPIO 电平

X3576 核心板包含多个 GPIO IO 电源域，不同电源域支持的工作电压不同。各 GPIO IO 电源域支持的电压范围及 X3576 核心板默认配置如下：

| IO 电源域 | 支持电压 | X3576 核心板配置 | 说明 |
| --- | --- | --- | --- |
| PMUIO0 | 1.8V | 1.8V | 固定为 1.8V |
| PMUIO1 | 1.8V / 3.3V | 3.3V | 核心板统一配置为 3.3V |
| VCCIO0 | 1.8V | 1.8V | 固定为 1.8V |
| VCCIO1 | 1.8V / 3.3V | 3.3V | 默认配置为 3.3V，可通过程序控制 LDO5 调整电压 |
| VCCIO2 | 1.8V / 3.3V | 3.3V | 核心板统一配置为 3.3V |
| VCCIO3 | 1.8V / 3.3V | 1.8V | 核心板统一配置为 1.8V |
| VCCIO4 | 1.8V / 3.3V | 3.3V | 核心板统一配置为 3.3V |
| VCCIO5 | 1.8V / 3.3V | 1.8V | 核心板统一配置为 1.8V |
| VCCIO6 | 1.8V / 3.3V | 3.3V | 核心板统一配置为 3.3V |
| VCCIO7 | 1.2V / 1.8V | 1.2V | 核心板统一配置为 1.2V |

### 底板设计注意事项

在进行底板设计时，应确认外设接口电平与其连接的 X3576 GPIO 所属 IO 电源域电压一致。

例如，当某 GPIO 所属 IO 电源域为 1.8V 时，与其连接的外设 IO 电平也应兼容 1.8V。若外设采用 3.3V IO，而对应 GPIO 电源域为 1.8V，则不能直接连接，应根据实际接口类型增加合适的电平转换电路。

> **注意：** 外设 IO 电平与核心板 GPIO 电平不匹配，可能导致通信异常、IO 功能异常，严重时可能造成芯片 IO 永久损坏。在进行底板设计前，请务必确认各接口所对应的 IO 电源域及工作电压。

## 电源设计

X3576 核心板仅需要主电源供电即可正常使用。详细的电源管脚定义如下：

159、160 脚：5V/3A 电源输入接口，为确保CPU 稳定可靠工作，务必保证提供足额电流且保证电源纹波电压控制在100MV 以下，另外电源走线尽可能宽（大于2MM），换层过孔不小于5 个；

161 脚：3.3V/1A 电源输出，可用于接口板电源供电（部分外设上电时序有要求，可参考上述核心板引脚定义的描述给对应外设供电）；

156 脚：1.8V/500MA 电源输出，可用于底板音频CODEC 和网络PHY 芯片的IO 域供电。

## USB 设计

X3576 核心板有2 路USB2.0 和2 路USB3.0 口。其中USB2.0 口在开发板上设计为固件升级（device）和USB HOST 复用，通过外部USB 5V 插入做检测并切换为DEVICE 而升级固件用。默认USB2.0 接口能达到480Mbps 的速度，而USB3.0 最快能达到5Gbps 的带宽，，因此，对PCB 走线的要求做特性阻抗匹配。USB 接口的差分对在PCB 走线时，务必走等长差分线，特性阻抗为90 欧-/+10%，而且需要有完整的参考平面。

## HDMI 设计

X3576 芯片自带一路HDMI OUT 控制器，支持HDMI2.0 协议。核心板上相应的HDMI差分对，必须走等长差分线，且阻抗匹配为100 欧-/+10%，否则会出现HDMI 画面丢色，断断续续等问题。

## MIPI 设计

MIPI 是2003 年由ARM，Nokia，ST，TI 等公司成立的一个联盟，目的是把手机内部的接口如摄像头、显示屏、射频基带接口等标准化，从而减少手机的设计复杂度，增加设计的灵活性。MIPI 是一个比较新的标准，目前比较成熟的应用有DSI（显示接口）和CSI（摄相头接口）。X3576 支持1 路MIPI DSI 和3 路MIPI CSI 接口，其中DSI 用于驱动MIPI 显示屏，CSI可以外接MIPI 摄像头。MIPI 接口的数据传输率较高，在走线时一定要走等长差分线，且阻抗匹配为100 欧-/+10%。
