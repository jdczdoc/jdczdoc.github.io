# 硬件设计

## 管脚复用

除高速专用接口、电源和系统地外，部分信号可复用为I2C、UART、SPI、I2S、PWM和GPIO等功能。底板设计前应结合核心板原理图和MediaTek管脚复用表确认：

- 默认上电状态和上下拉。
- IO电压域。
- 复用功能冲突。
- 驱动能力和外部负载。

## 电源设计

- 101、102、103脚为VSYS 5V输入，建议电源能力不低于3A。
- 主电源纹波控制在100mV以内。
- 主电源走线建议大于2mm；换层时使用不少于5个过孔。
- 77脚为VIO18_PMU电源输出。硬件设计正文标注约600mA，而参数表标注500mA；量产底板应以当前原理图、PMIC配置和实测余量为准。
- 79脚VCN33_1_PMU为3.3V输出，资料标注800mA。
- 80脚VCN18_PMU为1.8V输出，资料标注1.2A。
- 81脚VIO28_PMU为2.8V输出，资料标注200mA。

## USB设计

核心板引出3路USB2.0和1路USB3.0。开发板上的Micro USB用于固件升级Device模式。

- USB2.0理论带宽480Mbps。
- USB3.0理论带宽最高5Gbps。
- 差分对等长布线。
- 差分阻抗控制为90Ω ±10%。
- 差分线下方保持连续参考平面，避免跨分割和不必要的过孔。

## HDMI设计

MT8390集成HDMI OUT并支持HDMI 2.0。HDMI高速差分对要求：

- 组内和组间长度匹配。
- 差分阻抗100Ω ±10%。
- 保持完整参考平面。
- 减少过孔、支路和连接器不连续点。

阻抗或时序控制不当可能造成丢色、闪断和无显示。

## MIPI设计

核心板支持2路MIPI DSI和2路MIPI CSI。

- MIPI差分对等长布线。
- 差分阻抗100Ω ±10%。
- 确认DSI/CSI与复用引脚的实际模式。
- 摄像头供电、MCLK、RESET、PWDN和I2C电压域应与传感器匹配。
- 显示屏电源、复位、背光和触摸上电时序应按面板规格设计。

## PCIe、DP和eDP

PCIe、DisplayPort和eDP均属于高速接口。原手册未给出完整的长度、损耗和过孔预算，PCB投板前应以MediaTek硬件设计指南、核心板原理图和目标连接器规范为最终依据。
