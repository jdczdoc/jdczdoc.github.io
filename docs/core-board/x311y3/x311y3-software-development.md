# 软件与系统开发

## 5.1 支持的操作系统

X311Y3CV1支持 Android16与 Linux6.12.69。Android适合人机交互、商业显示、智能终端与多媒体应用；Linux 适合工业控制、边缘计算、机器视觉与定制化服务。具体 BSP、内核配置、设备树与驱动版本以九鼎创展发布的固件包为准。

**表5-1 支持的操作系统**

| 系统 | 版本 | 适用场景 |
| --- | --- | --- |
| Android | Android16 | 商业显示、智能终端、交互设备、多媒体 |
| Linux | Linux6.12.69 | 工业控制、边缘计算、机器视觉、定制服务 |

## 5.3 调试与故障排查

调试串口是定位问题的第一入口。上电后应先确认 12V、3.3V/1.8V、PWR_CTL1/2、RESET_N ，再查看 U-Boot/内核日志。常见问题包括电源不足、复位未释放、启动介质配置错误、eMMC虚焊、DDR初始化失败、显示时序不匹配与USB/PCIe复用冲突。

**表5-3 常见故障排查**

| 现象 | 优先检查 | 可能原因 |
| --- | --- | --- |
| 上电无串口输出 | 12V、3.3V、RESET_N、时钟 | 电源不足、复位拉低、晶振未起振 |
| 串口乱码 | 波特率、地线、TX/RX | 波特率错误、电平不匹配、干扰 |
| 无法进入烧录模式 | BOOT/POC、Type-C、驱动 | BOOT键时序、线材、USB驱动 |
| eMMC识别失败 | eMMC供电、焊接、DS | 虚焊、器件损坏、启动配置 |
| HDMI无显示 | HPD、DDC、TMDS、电源 | 连接器、ESD、阻抗、时序 |
| USB3.0不稳定 | SS差分、CC、VBUS | 阻抗、复用冲突、供电不足 |
| PCIe设备不识别 | REFCLK、PERST#、AC耦合 | 时钟、复位、供电、复用 |
| Wi-Fi无法启动 | SDIO、32K、WL_EN | 模组电源、固件、天线 |
