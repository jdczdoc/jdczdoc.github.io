# SoC 引脚与网络定义

原文说明写为 U1A–U1N 共 286 条映射，逐表提取实际得到 **287 行**，封装分区与球号组合均不重复。以下完整保留原表所有行，请结合受控引脚定义表核对数量差异。

:::caution

说明：附录 D 的电源引脚均为输入/参考/去耦，核心板不向外输出电源；VDD_EE、VDD_A78、VDD_A55、VDD_GPU、VDD_NPU、VDD_DDR、VDD_2H2、VDDQ由核心板内部DCDC产生，不引出。

:::

本附录根据随板《X311Y3开发板硬件手册》中的核心板引脚定义整理，覆盖 U1A 至 U1N 共14个封装分区、286条引脚/网络映射。表中“封装”为原理图U1A 至 U1N分区，“信号名称”为SoC引脚名，“板级连接”为设计资料中的连接说明。
