# 接口资源

本章按功能说明核心板引出的主要接口、关键信号与底板设计要点。接口能否同时使用取决于引脚复用与软件配置；涉及复用的接口在第3.10节集中说明。所有差分阻抗、走线长度与防护要求应在原理图评审和PCB评审中逐项确认。各表“接口电源域”列给出该引脚所属的核心板电源网络，“电压”列为其标称值（单位V）；“AVDD0V75/18_xxx”表示0.75V模拟核电源与1.8V模拟IO电源两个域，电压按相同顺序列出。

## 3.1 显示接口

A311Y3提供 HDMITX、HDMIRX 以及 MIPI DSI/eDP/LVDS复用显示输出，可覆盖从中小尺寸MIPI屏到4KHDMI显示器的多种应用。显示接口的时钟与数据均为高速差分信号，底板布线应优先保证参考平面完整、阻抗连续与ESD防护。

### 3.1.1HDMI TX

HDMITX 用于向显示器、电视、投影仪或采集设备输出音视频。接口包含 4对 TMDS 差分线（时钟 +3对数据）、DDC（SCL/SDA）、CEC、HPD 与+5V。A311Y3支持HDMI2.1a协议与eARC音频回传。

底板设计建议：HDMI连接器尽量靠近核心板；TMDS差分对按90Ω阻抗控制，差分对内等长，避免跨分割；DDC/CEC/HPD 加 ESD 防护；+5V 输出加限流与保险丝；eARC 差分对按 100Ω控制并远离高速时钟。

### 3.1.2HDMI RX

HDMI RX用于采集外部 HDMI 信号，可用于视频会议、录播、监看与图像处理。接口包含TMDS输入、DDC、CEC、HPD、+5V检测与 eARC。输入端应设计 5V检测分压与 ESD保护，避免热插拔时浪涌损坏SoC。

HDMIRX 的 TMDS差分对按 90Ω控制；输入连接器的 +5V引脚应通过电阻分压到 SoC 允许的电压域，不能直接接入5V。若产品需要长线输入，应评估均衡器/重驱动器的必要性。

### 3.1.3MIPI DSI / eDP / LVDS

核心板提供1路4-laneDIF复用输出，可配置为MIPIDSI、eDP或LVDS。MIPIDSI适合手机/平板类屏幕，eDP适合高分辨率笔记本屏，LVDS适合工业与车载屏。复用关系由硬件配置与软件设备树共同决定，不能在运行时随意切换。

DSI/eDP/LVDS差分对按100Ω控制，差分对内等长；eDPAUX按100Ω控制；DSI的TE、复位、背光 PWM/EN 与面板电源使能应单独引出。背光电源建议在底板上独立升压/恒流，避免与核心板3.3V共用导致屏闪。

## 3.2 摄像头接口

核心板提供 2路 4-lane MIPI CSI，分别对应 CSI_A/B 与 CSI_C/D。每路包含时钟差分对、4对数据差分对、MCLK、I2C 控制、复位与 PWDN。可连接 1300万/1600万像素摄像头，也可用于双目/多目视觉。

CSI差分对按100Ω控制，时钟与数据对之间、lane与lane之间应做等长；MCLK 为敏感时钟，应远离DCDC电感与高速开关节点；I2C上拉电阻应接到摄像头IO电源，不能与SoCIO域冲突；摄像头连接器应加ESD防护。

## 3.3 USB 接口

核心板提供 1 路 USB3.0 OTG Type-C、1 路 USB3.0 Host、1 路 USB2.0 Host 与 1 路 USB2.0OTG。Type-COTG支持HOST/Device双模式与DPAltMode，可用于系统烧录、ADB、外接显示器与USB外设。

USB3.0 差分对按 95 Ω 控制（USB3.0/PCIe2.0/HSGMII 复用组），USB2.0 差分对按 90Ω 控制，Type-C/DP复用差分对按90Ω控制。Type-C 的CC1/CC2需按角色配置 5.1kΩ下拉或 56kΩ上拉；VBUS需加ESD与限流；DPAltMode的AUX按100Ω控制。

## 3.4 PCIe 接口

核心板提供1路PCIe3.0x2与1路PCIe2.0x1。PCIe3.0x2可用于NVMeSSD、PCIe网卡、采集卡等高速设备；PCIe2.0x1与USB3.0Host复用，需在底板上二选一。

A311Y3的引脚复用非常灵活，同一组引脚可配置为多种功能。进行底板设计前，应先完成“接口—控制器—引脚—电平—复用”的分配表，避免原理图阶段出现功能冲突。表3-10列出需要重点关注的复用关系。
