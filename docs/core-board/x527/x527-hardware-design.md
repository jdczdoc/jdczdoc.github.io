# 硬件设计

## 管脚描述

除引脚表中明确标注为不可用作GPIO的接口、电源引脚和系统地外，X527核心板的其他GPIO通常可复用为I2C、UART、SPI、I2S和PWM等功能。实际设计时，应结合核心板原理图和T527/A527芯片规格书确认复用关系。

## GPIO电平

在设计底板时，需要确保外设芯片的IO电平与核心板对应IO电压域一致，否则可能损坏CPU或外设。

| VCC-PC | 1.8V / 3.3V | 1.8V |
| VCC-PD | 1.8V / 3.3V | 3.3V |
| VCC-IO | 3.3V | 3.3V |
| VCC-PG | 1.8V | 1.8V |
| VCC-PE | 1.8V / 3.3V | 1.8V |
| VCC-PI | 3.3V | 3.3V |
| VCC-PJ | 1.8V / 3.3V | 3.3V |
| VCC-PM | 1.8V / 3.3V | 1.8V |

## 电源设计

X527核心板仅需要主电源供电即可正常使用。

- 101、102、103脚为 `VCC-SYS-5V`，用于5V主电源输入。
- 建议电源能力为 **5V/3A**。
- 电源纹波应控制在 **100mV以下**。
- 主电源走线建议大于 **2mm**。
- 电源换层过孔建议不少于 **5个**。
- 109脚为 `DCDC4` 3.3V输出。
- 110脚为 `CLDO3` 3.3V输出。

> **参数差异：** 特性参数表将DCDC4标为3.3V/3A、CLDO3标为3.3V/500mA；硬件设计正文又将109、110脚合计描述为3.3V/1A。量产设计应以核心板原理图、AXP717B配置和实测结果为准。

## USB设计

X527核心板提供3路USB2.0和1路USB3.0。其中一路USB2.0在开发板上作为固件升级Device Type-C接口。

USB2.0理论带宽为480Mbps，USB3.0理论带宽最高为5Gbps。PCB设计时需要注意：

- USB差分线需要等长布线。
- 差分阻抗为 **90Ω ±10%**。
- 差分线下方需要保持完整参考平面。

## HDMI设计

X527集成一路HDMI OUT控制器，支持HDMI2.0。

- HDMI高速差分线需要等长布线。
- 差分阻抗为 **100Ω ±10%**。
- 阻抗或等长控制不当可能造成画面丢色、闪断或无显示。

## MIPI设计

硬件设计章节记录X527支持1路MIPI DSI和3路MIPI CSI：

- MIPI DSI用于连接显示屏。
- MIPI CSI用于连接摄像头。
- MIPI高速差分线需要等长布线。
- 差分阻抗为 **100Ω ±10%**。

接口实例数量、lane复用和IO电压仍应结合核心板原理图及实际电阻选配确认。
