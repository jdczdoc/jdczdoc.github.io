# 产品介绍

i3128核心板简介

产品简介

I3128CV1是基于瑞芯微RK3128的一款高性价比核心板，它由深圳市九鼎创展科技有限公司自主研发，生产并销售。它是一款低成本A7四核，主频1.3GB的高性价比核心板。RK3128集成Mali-400 MP2图形处理器，支持OpenGL ES1.1/2.0，内嵌高性能2D硬件加速，并能实现1080P的H.265视频硬解码和H.264视频编码，安兔兔跑分超过14000分，拥有不俗的性能，而其极低的成本，凸显其超高的性价比。

I3128CV1核心板广泛应用于人机交互，智能控制系统，便携手持投影仪，机顶盒，医疗，车载，POS等领域，尤其适合于对成本敏感，性能又有较高要求的应用场景。

核心板特性

I3128CV1核心板具有以下特性：

最佳尺寸，保证引出全部GPIO口的同时，尺寸仅38mm*38mm；

使用RK自身的RK816 PMU，在保证工作稳定可靠的同时，成本足够低廉；

支持多种品牌，多种容量的emmc；

使用单片DDR3设计，可支持512MB/1GB/2GB容量,默认512MB；

支持电源休眠唤醒；

支持android6.0、linux等操作系统；

支持SPI、I2C、UART等通讯总线；

支持千兆有线以太网；

产品稳定可靠，经过大量高低温，反复重启，安卓稳定性测试，安兔兔测试等可靠性实验，拷机7天7夜不死机；

特性参数

### 系统配置

| 项目 | 参数 |
| --- | --- |
| CPU | RK3128 |
| 主频 | A7四核1.3GHz |
| 内存 | 标配512MB，可定制1GB及2GB |
| 存储器 | 标配4GB EMMC，可选配nand flash |
| 电源IC | 使用RK816，支持动态调频等 |


### 接口参数

| 项目 | 参数 |
| --- | --- |
| LCD接口 | TTL、LVDS、MIPI接口三选一 |
| Touch接口 | 电容触摸，可使用USB或I2C接口触摸 |
| 音频接口 | AC97/IIS接口，支持录放音 |
| SD卡接口 | 2路SDIO输出通道 |
| emmc接口 | 板载emmc接口，管脚不另外引出 |
| 以太网接口 | 支持千兆以太网 |
| USB OTG接口 | 1路OTG2.0 |
| USB HOST接口 | 1路HOST2.0 |
| UART接口 | 3路串口，2路带流控，1路用于DEBUG |
| PWM接口 | 3路PWM输出 |
| IIC接口 | 4路IIC输出 |
| SPI接口 | 1路SPI输出 |
| ADC接口 | 3路ADC输入 |
| Camera接口 | 1路BT656/BT601 |
| HDMI接口 | 高清音视频输出接口，LCD和HDMI二选一 |
| 启动配置接口 | 无需启动配置，核心板自动适配 |


### 电气特性

| 项目 | 参数 |
| --- | --- |
| 4V输入电压 | 4.8~5.5V(推荐使用5V输入) |
| 输出电压 | 3.3V/4.2V(可用于底板供电及电池充电) |
| 工作温度 | 0~70度 |
| 储存温度 | -10~40度 |
