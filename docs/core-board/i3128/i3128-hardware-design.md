# 硬件设计

硬件设计

管脚描述

RK3128除差分对、ADC输入脚外的GPIO口都可以复用作其他功能，如I2C、UART、SPI、I2S、PWM等等。因篇幅有限，本文描述不尽详细，如有需要，可以通过仔细阅读核心板原理图获取更多信息。

GPIO电源

GPIO电源域的电源脚描述如下：

| 电源域 | GPIO类型 | 描述 | I3128核心板电平 |
| --- | --- | --- | --- |
| VLDO1 | 2.8V | VCC28_CIF | 2.8V |
| VLDO2 | 1.8V | VCC18_CIF | 1.8V |
| VLDO3 | 1.1V | VDD_11 | 1.1V |
| VLDO4 | 1.1V | VDD_11_HDMI | 1.1V |
| VLDO5 | 3.0V | VCCA_CODEC | 3.0V |
| VLDO6 | 3.0V | VCC_TP/VCC33_HDMI | 3.0V |
| DCDC1 | 1.1V | VDD_ARM | 1.1V |
| DCDC2 | 1.1V | VDD_LOG | 1.1V |
| DCDC3 | 1.5V | VCC_DDR | 1.5V |
| DCDC4 | 3.3V | VCC_IO/VCCIO_WL/VCC_SD / FLASH/VCC_LCD | 3.3V |


电源设计

I3128CV1核心板采用5V供电的方式，用户只需给第59、60、61管脚供5V的直流电，核心板即可以正常工作。另外，核心板还有一些其他的电源管脚，具体定义如下：

1、59、60、61脚：核心板电源供电端，默认输入4.8到5.5V/1A；

2、56脚：RTC电源输入，3V/50mA；

3、57、58脚：电池接口，用于电池供电；

4、24、25、48、49脚：核心板公共地；

5、53、54脚：通过电源适配器或电池给核心板供电后，PMU的公共电源输出端，通常电压在3.5V到5V之间，具体受输入电压决定，它可以给整机供电；

6、62、63脚：3.3V输出，可用于底板供电。
