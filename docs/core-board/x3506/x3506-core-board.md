# 产品介绍

## 产品简介

X3506核心板是基于瑞芯微 RK3506 CPU 研发的一款核心板，由深圳市九鼎创展科技有限公司自主研发、生产并销售。

RK3506 是一款系统级芯片（SoC），集成 Cortex-A7 和 Cortex-M0 核心，适用于智能物联网设备。它具备丰富接口，支持 Linux 操作系统，适用于智能家居、楼宇对讲、PLC 等 AIoT 解决方案。

## 核心板特性

- 尺寸为 **40mm × 40mm**，适合小型化产品设计。
- 使用 DDR3 设计。
- 支持以太网、MIPI-DSI、USB2.0 等高速接口。
- 采用邮票孔封装，便于底板集成。

## 特性参数

### 系统配置

| CPU | RK3506 (Cortex-A7 +Cortex-M0) |
|---|---|
| 主频 | 1.5GHz |
| RAM | 512MB |
| ROM | 256MB / 8GB可选 |
| 电源IC | 使用DCDC |

### 接口参数

| emmc 接口 | 板载EMMC |
|---|---|
| USB 接口 | 2路USB接口 |
| LCD 接口 | 1路MIPI DSI/1路RGB |
| SPI 接口 | 3路 |
| I2C接口 | 3路 |
| UART接口 | 6路 |
| SDIO接口 | 1路 |
| RMII接口 | 2路 |
| ADC接口 | 4路 |
