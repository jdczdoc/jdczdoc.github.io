# 硬件设计

## 管脚描述

除不可用作 GPIO 的管脚、电源引脚和系统地之外，X3506 核心板的其他信号引脚通常可复用为 I2C、UART、SPI、I2S、PWM 等功能。实际设计时请结合核心板原理图和 RK3506 芯片规格书确认复用关系。

## GPIO电平

在设计底板时，需要确保外设芯片的 IO 电平与核心板对应 IO 电压域一致，否则可能损坏 CPU 或外设。

| 电源域 | GPIO供电电压 | 描述 | X3506核心板IO默认电平 |
|---|---|---|---|
| PMUIO_VCC3V3 | 3.3V | 电压域不可调 | 3.3V |
| SYS_PLL_AVDD1V8 | 1.8V | 电压域不可调 | 1.8V |
| VCCIO2_VCC | 1.8V/3.3V | 电压域可调 | 3.3V |
| SARADC_AVDD1V8 | 1.8V | 电压域不可调 | 1.8V |
| MIPI_DPHY_AVDD1V8 | 1.8V | 电压域不可调 | 1.8V |
| VCCIO1_VCC | 1.8V/3.3V | 电压域可调 | 3.3V |
| VCCIO3_VCC | 1.8V/3.3V | 电压域可调 | 3.3V |
| VCCIO4_VCC | 1.8V/3.3V | 电压域可调 | 1.8V |

## 电源设计

X3506核心板仅需要主电源供电即可正常使用。

- 115、116、117 脚为 `VCC5V0_SYS`，用于 5V 电源输入。
- 建议使用 **5V/3A** 电源。
- 为确保 CPU 稳定可靠工作，电源纹波建议控制在 **100mV 以下**。
- 电源走线应尽可能加宽，建议大于 **2mm**。
- 电源换层过孔建议不少于 **5 个**。

## USB设计

X3506核心板提供 2 路 USB2.0。USB2.0 可设计为固件升级 Device 口和 USB Host 口复用，通过外部 USB 5V 插入检测切换为 Device 模式用于固件升级。

USB2.0 理论速率可达 480Mbps，PCB 设计时需要注意：

- USB 差分线需要等长布线。
- 差分阻抗建议为 **90Ω ±10%**。
- 需要保持完整参考平面。

## MIPI设计

X3506支持 1 路 MIPI DSI，用于驱动 MIPI 显示屏。MIPI 接口速率较高，PCB 设计时需要注意：

- MIPI 差分线需要等长布线。
- 差分阻抗建议为 **100Ω ±10%**。
- 走线尽量短、少换层，并保持完整参考平面。
