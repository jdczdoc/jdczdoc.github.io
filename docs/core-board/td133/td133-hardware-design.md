# 硬件设计与调试

## 电源与控制信号

| 接口 | 引脚 | 说明 |
| --- | --- | --- |
| PS | 149–151 | 主电源输入，5 V / 2 A |
| ACIN | 152–153 | 5 V 电源输入 |
| VBUS | 142 | 5 V 输入 |
| VBAT | 154–155 | 单节电池输入，手册标注 4.2 V |
| DCDCE/VCC3V3 / ALDO3 | 5–6 | 3.3 V 电源输出 |
| BLDO4/DVDD-CSI / AVDD-CSI / VCC-CSI | 9–11 | 摄像头电源输出，电压见引脚定义 |
| AVCC | 145 | 1.8 V / 0.5 A 输出 |
| PWRON | 2 | 低电平触发开机 |
| RESET | 3 | 低电平复位 |
| FEL | 4 | 低电平进入烧录模式 |

电源输入建立后，由 AXP707 建立板内电源。按对应底板设计触发 PWRON，并在电源稳定后释放 RESET。第 7、8 脚在引脚定义和系统控制表中为 1.8 V GPIO。用于电源设计前，请按对应版本原理图核对。

## I/O 电平

| 电源域 | I/O 电平 |
| --- | --- |
| PC | 1.8 V |
| PD | 3.3 V |
| LVDS | 1.8 V |
| PE | 1.8 V |
| PG | 3.3 V |
| PL | 3.3 V |

接外设时核对接口模式和对应引脚电平。复用为 LVDS 的引脚按 1.8 V 电平域设计。

## 载板布线

| 信号 | 目标阻抗 | 类型 |
| --- | --- | --- |
| USB 2.0 | 90 Ω ±10% | 差分 |
| MIPI DSI / CSI | 100 Ω ±10% | 差分 |
| LVDS | 100 Ω | 差分 |
| SDC0 | 50 Ω | CLK、CMD、DATA |

高速差分对保持对内等长，沿连续参考平面布线。换层时在信号过孔附近留回流地孔。RGMII 的单端阻抗和时序应结合 PHY 与 PCB 叠层确认。外露接口预留 ESD 保护。

## 调试串口

默认调试口为 UART0，核心板第 110 脚是 RX，第 111 脚是 TX，电平为 3.3 V。使用 3.3 V USB 转 TTL 适配器，将适配器 TX 接核心板 RX，适配器 RX 接核心板 TX，并共地。终端设置为 **115200 baud，8 个数据位，无校验，1 个停止位**。
