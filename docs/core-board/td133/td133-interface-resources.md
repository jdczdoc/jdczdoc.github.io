# 接口资源

下表列出主要接口及对应焊盘。每脚的完整复用信号见[引脚定义](./td133-pin-definition.md)。同一焊盘的复用功能需在载板设计和固件配置中一起考虑。

## 显示与摄像头

| 接口 | 引脚 | 说明 |
| --- | --- | --- |
| MIPI DSI | 20–29 | 四条数据差分对和一条时钟差分对，与 LVDS0 复用 |
| LVDS0 | 20–29 | 与 MIPI DSI 共用焊盘 |
| LVDS1 | 12、13、18、19、30–35 | 独立的 LVDS1 数据和时钟信号 |
| MCSIA | 52–61 | 四条数据差分对和一条时钟差分对 |
| MCSIB | 62–67 | 两条数据差分对和一条时钟差分对 |
| MIPI_MCLK0 | 47 | 摄像头参考时钟 |

背光控制可从第 14–17 脚的 PWM 或第 101 脚的 `S_PWM` 选择。第 63 脚在引脚表中为 `MCSIB-D0P`。如设计需要独立的 MCLK1，请先核对对应版本原理图。

## USB、网络与存储

| 接口 | 引脚 | 说明 |
| --- | --- | --- |
| USB1 | 37–38 | DM、DP |
| USB0 | 40–41、140 | DM、DP 和 USB0-DRVVBUS |
| RGMII / MDC / MDIO | 90、93、100、102、116–119 | 手册已列出的管理、数据及控制信号 |
| SDC0 | 83、85–89 | 4 位 TF 卡接口，第 86、89 脚可复用为 UART0 |

接外部千兆 PHY 前，需在对应版本原理图中核对完整 RGMII 信号。TF 卡信号在引脚表中标为 1.8 V，设计时核对卡座供电和电平转换。

## 音频与低速接口

| 接口 | 引脚 | 说明 |
| --- | --- | --- |
| Audio | 68–78、80、139 | 耳机输出、检测、偏置、LINE OUT、两路麦克风和耳机地参考 |
| UART0 | 110–111 | 3.3 V 调试串口，RX、TX |
| UART2 | 95–98 | 含流控 |
| UART3 / SPI1 | 122–125 | UART3 与 SPI1 复用 |
| UART4 | 12、13、15、16 | 与显示相关信号复用 |
| TWI2 / TWI3 | 48–51 | 1.8 V 摄像头控制总线信号 |
| SPI2 | 90–93、95–98 | 含两组复用脚位，按引脚表选择 |
| I2S0 / I2S2 / I2S3 | 43–46、90–94、99、100、102、104、106–109、127、129、131、133 | 音频串行总线，按引脚复用选择 |
| LRADC | 120 | 低速 ADC 输入 |
