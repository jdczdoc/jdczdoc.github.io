# 硬件设计

## 管脚描述

X507CV1手册列出了核心板172PIN的信号名称和接口类型，但没有给出完整的GPIO复用功能及各GPIO电源域电平。底板设计时，应结合核心板原理图和T507芯片规格书确认复用关系、IO电平、上下拉和上电默认状态。

## 电源设计

X507CV1核心板使用5V主电源供电。

- 159、160脚为 `ACIN`，用于5V主电源输入。
- 161、162脚为系统地。
- 163、164脚为 `DCDC1`，提供3.3V电源输出。
- 特性参数中给出的主电源规格为 **5V/2A**。
- 3.3V输出能力标称为 **3.3V/1.5A**。
- RTC输入规格为 **3V/0.6µA**。
- 23脚为 `PMU-PWRON`，用于电源键输入。

底板投板前，应根据核心板原理图确认电源上电时序、输出电源允许负载和去耦要求。

## USB设计

X507CV1引出1路USB OTG和3路USB2.0 Host信号：

| 接口 | 引脚 |
|---|---|
| USB0 OTG | 47：USB0-DM；48：USB0-DP |
| USB1 | 49：USB1-DM；50：USB1-DP |
| USB2 | 51：CON-USB2-DM；52：CON-USB2-DP |
| USB3 | 53：USB3-DP；54：USB3-DM |

原手册没有给出USB差分阻抗、VBUS开关和OTG角色检测的详细电路要求，相关设计应以T507参考设计和核心板原理图为准。

## HDMI设计

HDMI输出相关信号位于55～66脚，包括CEC、DDC、HPD、时钟差分对和3组数据差分对。

| 功能 | 引脚 |
|---|---|
| CEC | 55：HCEC |
| DDC | 56：HSDA；57：HSCL |
| 热插拔检测 | 58：HHPD |
| TMDS时钟 | 59：HTXCN；60：HTXCP |
| TMDS数据0 | 61：HTX0N；62：HTX0P |
| TMDS数据1 | 63：HTX1N；64：HTX1P |
| TMDS数据2 | 65：HTX2P；66：HTX2N |

原手册没有给出HDMI高速差分线的具体阻抗和长度匹配要求，PCB设计时应使用T507 HDMI参考设计作为最终依据。

## 显示接口设计

X507CV1引出RGB/LVDS复用显示信号，主要位于67～95脚，包括LCD数据、时钟、行场同步、数据使能和背光PWM信号。

RGB与LVDS信号存在复用关系，使用前需要结合核心板原理图、底板电阻配置和软件设备树确认实际输出模式。

## 摄像头接口设计

核心板提供MIPI CSI和并行CSI接口：

- 34～46脚为MIPI CSI控制和4 lane差分信号。
- 128～150脚为NCSI并行摄像头信号以及帧同步信号。

摄像头电源、复位、MCLK、电平域和lane数量应结合具体传感器及T507摄像头参考设计确认。
