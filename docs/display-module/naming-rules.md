# 九鼎创展液晶模组命名规则

型号由模组类型、液晶屏尺寸、分辨率代码和接口代码组成。例如，`LCD040D25MM` 表示 4 寸、480 × 480 分辨率、MIPI 接口的液晶模组。

## 型号结构

| 字符位置 | 含义 | 示例 |
| --- | --- | --- |
| 1–3 | 模组类型 | LCD：液晶模组 |
| 4–6 | 液晶屏尺寸 | 040：4 寸 |
| 7–9 | 分辨率代码 | D25：480 × 480 |
| 10–11 | 液晶屏接口 | MM：MIPI |

## 液晶屏尺寸代码

| 代码 | 尺寸（寸） |
| --- | --- |
| 040 | 4 |
| 043 | 4.3 |
| 048 | 4.8 |
| 050 | 5 |

| 080 | 8 |

## 分辨率代码

D 表示分辨率代码前缀，代码不区分横屏和竖屏。D25 在九鼎创展型号中专用于 480 × 480；通用显示模式对照表第 25 项则为 PAL（768 × 576）。

| 代码 | 分辨率 |
| --- | --- |
| D25 | 480 × 480 |
| D26 | 800 × 480 |
| D51 | 1920 × 1080 |
| D32 | 1024 × 600 |
| D33 | 1024 × 768 |
| D38 | 1280 × 800 |
| D52 | 1920 × 1200 |
| D60 | 2560 × 1600 |

## 接口代码

| 代码 | 接口 |
| --- | --- |
| MM | MIPI |
| RR | RGB |
| L1 | LVDS，适配 X3288 开发板 |
| L2 | LVDS，适配 X30 开发板 |
| EL | eDP 转 LVDS |
| ML | MIPI 转 LVDS |
| EE | eDP |
