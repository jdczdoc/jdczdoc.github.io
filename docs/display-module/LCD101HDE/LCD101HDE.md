## 二、产品简介
LCD101HDE液晶模组针对x3399开发平台，分辨率为2560x1600，即现在比较流行的高清2K屏。默认模组已经开了塑胶模，模组内部包含2K液晶屏，液晶屏控制板以及触摸屏，用户只需要通过一根30PIN的FPC排线接到x3399开发板的EDP接口即可正常使用了。

## 三、特性参数
| 项目         | 规格描述             |

| 外形尺寸     | 260mm*177.8mm*17.5mm |
| 液晶屏型号   | LTL101DL03-T01       |
| 触摸IC型号   | GT9271               |
| 分辨率       | 2560*1600            |
