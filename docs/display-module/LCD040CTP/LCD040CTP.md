# LCD040CTP 显示模组

## 一、产品外观
![LCD040CTP产品外观](./LCD040CTP_01.jpg)

## 二、产品简介
LCD040CTP液晶模组针对九鼎创展x3128/x30等开发平台，分辨率为480x800。模组内部包含液晶屏，液晶屏控制板以及触摸屏，用户只需要通过一根30PIN的FPC排线接到x3128/x30等开发板的MIPI接口即可正常使用了。

## 三、特性参数
| 项目       | 规格描述       |
|------------|----------------|
| 外形尺寸   | 120mm*61mm*9mm |
| 液晶屏型号 | TXW397047S0    |
| 触摸IC型号 | GT911          |
| 分辨率     | 480*800        |
