# 配置清单

## 标配硬件清单

- X6818 开发板一套。
- 7 寸 TFT 液晶屏，可支持 RGB 或 MIPI 接口。
- 5V 电源适配器。
- USB 数据线。
- 串口线。
- 网盘资料和官方资料链接。

## 选配硬件清单

- 4.3 寸、5 寸或 7 寸液晶屏。
- LVDS 屏、MIPI 屏、RGB 屏。
- 摄像头模块。
- USB Wi-Fi/BT 模块。
- USB 3G 模块或 PCIe 3G/4G 模块。
- TF 卡。
- 喇叭。
- GPS / GPRS 模块。

## 开发板资料清单

资料通常包含硬件手册、Android 平台用户手册、Linux 平台用户手册、原理图、PCB 相关资料、系统镜像、源码包、烧录工具、串口工具和常用测试程序。
