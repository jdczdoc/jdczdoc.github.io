# 配置清单

## 标配硬件

- X8390/X8370开发板一套。
- 电源适配器一个。
- Type-C数据线一根。
- USB转TTL串口转接板一个。
- 配套资料下载方式，由客服或项目交付人员提供。

硬件规格页建议12V/3A输入；原手册标准清单写有12V/2A适配器。实际交付和高负载场景应以当前硬件BOM及供电要求为准。

## 选配硬件

- 外置喇叭。
- 8GB或更大容量TF卡。
- 7英寸1024 × 600电容触摸MIPI液晶模组。
- Wi-Fi / Bluetooth模块。
- MIPI摄像头模组。
- 锂电池与匹配线材。
