# 硬件设计

## 核心板设计

X3128 核心板背面预留电容位。由于 RK3128 属于入门级芯片，常见低成本设计多采用百兆网口，因此默认核心板背部电容空贴。如果项目需要千兆以太网，建议贴装背部电容，降低丢包率。底板设计时需要参考开发板开孔位置，避开背部电容。

为便于区分，背部不贴电容的核心板型号为 X3128CV4，贴有电容的核心板型号为 X3128CV4P。

## 电源设计

X3128CV4 核心板采用 5V 供电，用户给第 115、116、117 管脚提供 5V 直流电后，核心板即可正常工作。

关键电源管脚如下：

- 115、116、117 脚：核心板电源输入，默认 4.8V 到 5.5V / 1A。
- 119 脚：RTC 电源输入，3V / 50mA。
- 120、121 脚：电池接口，用于电池供电。
- 72、73、109、110 脚：公共地。
- 1、144 脚：PMU 公共电源输出，通常在 3.5V 到 5V 之间，具体取决于输入电压，可给整机供电。
- 123、124、125、126 脚：PMU LDO1、LDO2、LDO6、LDO5 输出，电压可调。
- 36、37 脚：3.3V 输出，可用于底板供电。

## USB 设计

RK3128 提供 1 路 HOST 和 1 路 OTG。OTG 口既可作为 HOST，也可作为 DEVICE。

PCB 设计时，第 23、24 脚 HOST_DP / HOST_DM 需要作为一对 USB 差分线处理；第 25、26 脚 OTG_DP / OTG_DM 也需要作为一对 USB 差分线处理。建议做等长和阻抗控制，阻抗匹配约 90 欧，否则可能出现 USB 传输不稳定。

## HDMI 设计

RK3128 自带 HDMI 控制器，支持 HDMI 2.0。核心板第 12 到 19 脚为 HDMI 4 对差分线，需要等长走线并做约 100 欧阻抗匹配，否则可能出现 HDMI 画面丢色、显示断续等问题。

## LCD 接口设计

RK3128 自带 RGB、LVDS、MIPI LCD 控制器。为节省成本，这三组 LCD 管脚完全复用，即 RGB / LVDS / MIPI 三选一，不能同时使用。配置为 LVDS 或 MIPI 时，适合驱动较高分辨率液晶屏，走线需要等长差分并做阻抗匹配，推荐阻抗约 100 欧。
