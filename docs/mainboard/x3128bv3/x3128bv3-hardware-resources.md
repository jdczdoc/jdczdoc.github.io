# 硬件资源

本页整理 X3128BV3 主板正反面的硬件接口位置和接口说明。详细核心板 144PIN 定义见[引脚定义](./x3128bv3-pin-definition)，接口使用说明见[接口说明](./x3128bv3-interface-details)。

## 正面接口位置

![X3128BV3 正面接口位置](./x3128bv3-interface-front.png)

| 标号 | 名称 | 说明 |
| --- | --- | --- |
| 【1】 | DC座 | 12V DC电源输入 |
| 【2】 | TF卡 | TF卡座 |
| 【3】 | USB OTG | USB OTG接口 |
| 【4】 | RESET | 复位按键 |
| 【5】 | HDMI | HDMI输出接口 |
| 【6】 | 千兆网口 | RT8211E 接口 |
| 【7】 | GPIO | GPIO扩展口 |
| 【8】 | 锂电池接口 | 3.7V锂电池接口 |
| 【9】 | RTC电池插座 | RTC电池座，3V |
| 【10】 | 喇叭接口 | 外置扬声器接口 |
| 【11】 | 麦克风 | 麦克风输入 |
| 【12】 | MIPI/LVDS接口 | 接MIPI或LVDS接口的屏 |
| 【13】 | UART1 | 串口1，TTL电平 |
| 【14】 | UART0 | 串口0，TTL电平 |
| 【15】 | GPIO | GPIO扩展口 |
| 【16】 | Wi-Fi/BT | RT8723BU Wi-Fi/BT二合一模块 |
| 【17】 | USB HOST | HUB芯片扩展，双路HOST 2.0 |
| 【18】 | POWER | 电源按键 |
| 【19】 | 独立按键 | Recovery刷机键，按键K1 |
