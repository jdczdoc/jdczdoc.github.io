## 说明

- Linux 4.4 + Android 9.0 列中，表格内以“●”标记的项目表示已支持。
- Linux 4.4 + Qt 5.9 列中，多数项目标记为“即将支持”。
- Android 用户手册中同时出现 X8385 Android13 源码包和 Android 13 相关烧录流程，实际系统版本以网盘 SDK 和固件包为准。
