# 配置清单

## 标配硬件清单

- X8385CV1 核心板。
- X8385 底板。
- 7 寸 MIPI 液晶板。
- 12V 电源适配器。
- Android / Linux 系统镜像与源码资料。
- 烧录工具、驱动工具和用户手册。

## 选配硬件清单

- MIPI 摄像头。
- USB 摄像头。
- TF 卡。
- USB 鼠标、键盘、U 盘。
- 调试串口线。
- 喇叭、耳机、麦克风等音频外设。
- 其他 GPIO / I2C / SPI / UART 扩展外设。
