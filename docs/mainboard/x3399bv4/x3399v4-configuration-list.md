# 配置清单

## 标配硬件清单

- X3399 开发板一套，带 7 寸 1024 × 600 电容触摸 MIPI 液晶模组。
- 12V / 2A 电源适配器 1 个。
- Type-C 数据线 1 根。
- 串口线 1 根。
- 网盘资料链接，可通过官方 WIKI 查询。

## 选配硬件清单

- 喇叭一个。
- 8G TF 卡一张。
- 7.9 寸 2K MIPI 屏液晶模组一个。
- 7.9 寸 2K EDP 屏液晶模组一个。
- 10.1 寸 1280 × 800 MIPI 屏液晶模组一个。
- 10.1 寸 2K EDP 屏液晶模组一个。
- 1300W 像素 OV13850 摄像头一个。
- 500W 像素 OV5645 摄像头一个。
- 支持 x210、x4412、x3288、x3399 的 HDMI 线一根。
- USB 转串口线一根。
- USB 3G 上网卡一个。
- PCIe 接口 3G 模块一个。
- PCIe 接口 4G 全网通模块一个。
- TVIN 模块一个。
- USB Wi-Fi / 蓝牙二合一模块一个。
- GPS 模块一个。
- GPRS 模块一个。
- USB 摄像头一个。
