## Android 测试程序

测试程序可用于量产、硬件验证和驱动调试。进入测试界面后，可通过触摸或鼠标滑动切换不同硬件测试项。

### 液晶屏测试

点击屏幕纯色区域，观察颜色变化，用于检查 LCD 丢色、坏点和背光异常。

### 触摸屏测试

点击开始测试后在屏幕上划线。量产时常用画对角线方式检查触摸电路和坐标映射。

### LED / 蜂鸣器 / 背光测试

- LED：点击界面上的灯图标，观察对应 LED 亮灭。
- 蜂鸣器：按住测试键蜂鸣器鸣叫，松开后停止。
- 背光：滑动亮度条检查背光亮度调节是否正常。

### 按键测试

按下或抬起独立按键，界面应显示对应按键事件。若无响应，应检查 GPIO、按键驱动和设备树配置。

### 电池 / ADC / 传感器测试

电池界面显示电量信息；ADC 界面显示采样电压；重力传感器、陀螺仪、指南针、光线传感器用于验证对应 I2C/SPI 设备和 HAL 配置。

### 音频测试

播放测试音频，验证喇叭、耳机、MIC、LINE IN 等音频通路。

### 摄像头测试

连接摄像头后点击开始测试，界面应显示预览画面。若无图像，应检查供电、复位、MCLK、I2C、MIPI/CSI 和驱动匹配。

### 无线网络 / 有线网络测试

无线测试用于扫描和连接 Wi-Fi；网络连接测试用于验证有线或无线网络能否正常访问网页或 ping 通目标地址。

### 串口测试

将待测串口 TXD 和 RXD 短接，点击开始测试后应能自发自收。如果不能自收，需检查串口复用、电平、线序和驱动节点。

## Android 内核驱动

手册中的驱动入口包括：

- G-sensor 驱动
- 光感传感器驱动
- 电容触摸屏驱动
- 液晶屏驱动
- 按键驱动
- Wi-Fi/BT 模块驱动
- 摄像头驱动
- HDMI 驱动
- proc 文件系统查询

## 常用 proc 查询

### CPU 信息

```bash
cat /proc/cpuinfo
```

### 内存信息

```bash
cat /proc/meminfo
```

### 磁盘分区信息

```bash
cat /proc/partitions
```

### 内核版本

```bash
cat /proc/version
uname -a
```

### 网络设备

```bash
ifconfig
ip addr
```

### 内核启动信息

```bash
dmesg
dmesg | grep -i error
```

## Android 项目实战

常见项目修改包括：

- 修改 `init.rc` 文件。
- 修改开机动画。
- 修改 U-Boot 阶段开机 LOGO。
- 修改 Kernel 阶段 LOGO。

这些操作建议先在源码仓库中形成补丁，再通过完整编译和烧录验证。
