# 硬件设计

## 电源设计

X3399CV3、X3399CV4 核心板在底板硬件设计上没有区别，核心板采用 3.3V 供电方式。底板需要给第 51、52 脚供 3.3V / 4.3A 直流电，给第 42 脚供 3.3V / 300mA 直流电，给第 37 脚 RTC 供 2.5V 到 3V 电源，核心板即可正常工作。

:::warning
第 51、52 脚的 3.3V 供电和第 42 脚的 3.3V 供电不能合并，否则可能出现关机状态未知的问题。
:::

| 管脚 | 说明 |
| --- | --- |
| 37 | 核心板 RTC 供电端，默认输入 2.5V 到 3V / 5uA |
| 42 | 3.3V / 300mA 电源输入，任何情况下都需要常供电，以保证 PMU 工作或待命 |
| 51、52 | 3.3V / 4.3A 电源输入，仅开机时需要输入，关机后电压为 0 |
| 53、84、182 | 核心板公共地 |
| 120 | 1.8V / 1.5A 电源输出，可用于给底板 1.8V 外设供电，休眠或关机后电压为 0 |

## USB 设计

USB 2.0 默认速率可达 480Mbps，USB 3.0 最高带宽可达 5Gbps。PCB 走线时，USB 差分对必须走等长差分线，阻抗匹配为 90Ω，并保证完整参考平面。

| 差分管脚编号 | 差分管脚名称 |
| --- | --- |
| 114、115 | USB3_DM、USB3_DP |
| 116、117 | HOST0_DM、HOST0_DP |
| 118、119 | HOST1_DM、HOST1_DP |
| 109、110 | USB3_SSRXP、USB3_SSRXN |
| 107、108 | USB3_SSTXP、USB3_SSTXN |
| 105、106 | Type-C0_DM、Type-C0_DP |
| 103、104 | Type-C0_TX2P、Type-C0_TX2N |
| 101、102 | Type-C0_RX2N、Type-C0_RX2P |
| 99、100 | Type-C0_TX1P、Type-C0_TX1N |
| 97、98 | Type-C0_RX1N、Type-C0_RX1P |


## HDMI 设计

RK3399 芯片自带 HDMI 控制器，支持 HDMI 2.0。核心板第 85 到 92 脚共 8 个管脚组成 4 对差分线，必须走等长差分线，阻抗匹配为 100Ω，否则可能出现 HDMI 画面丢色、断续等问题。

## EDP 设计

RK3399 自带 EDP LCD 控制器。EDP 为差分信号，适合驱动高分辨率液晶屏。EDP 接口包括 5 组差分对，对应核心板第 135 到 144 脚。EDP 数据传输总容量可达 21.6Gbps，是 LVDS 的 3 倍，能够驱动 2K、4K 等高分辨率屏。走线时 5 组差分对需要等长，阻抗匹配为 100Ω。

## MIPI 设计

RK3399 支持 DSI 和 CSI。DSI 对应核心板第 74 到 83 脚，用于 MIPI 显示屏；CSI 对应核心板第 64 到 73 脚，用于 MIPI 摄像头。另外一路 MIPI 接口可作为 DSI 或 CSI 使用，对应核心板第 54 到 63 脚。MIPI 数据传输率较高，走线时必须等长，阻抗匹配为 100Ω。
