# Android 使用指南

本页整理系统启动后的常用功能操作，包括命令终端、音视频、网络、蓝牙、外设挂载、HDMI、开关机和休眠唤醒。

## 命令终端

连接调试串口后，主板进入 Android 系统会输出串口日志。也可以使用 adb 进入系统终端：

```bash
adb shell
```

## 播放 MP3 / 视频

将音频或视频文件放入 TF 卡、U 盘或内部存储后，可通过系统播放器或第三方播放器播放。对于 RK3399 支持硬解的视频格式，建议优先选择硬解模式；不支持硬解的格式可使用软解播放器。

## 使用 WIFI 上网

进入系统设置，打开 Wi-Fi，选择无线网络并输入密码。I3399 板载 2.4G/5G 双频 WIFI/BT 模块，可直接连接无线网络。

## 使用蓝牙传输数据

进入“设置 -> 蓝牙”，打开蓝牙后搜索外部设备。配对成功后，可通过系统分享菜单选择蓝牙发送图片、音频或其他文件。

## 使用蓝牙播放音乐

打开蓝牙音箱并切换到蓝牙模式，在 I3399 蓝牙设置界面搜索并配对。配对成功后，系统音频可通过蓝牙音箱播放。

## 使用 USB 鼠标键盘

将 USB 鼠标、键盘或无线接收器接入 USB HOST 接口后，即可操作 Android 界面。

## 挂载 TF 卡

插入 TF 卡后，Android 系统会自动挂载到外部存储路径。具体挂载路径可能因系统版本不同而变化，可通过文件管理器或 `mount` 命令查看。

## 挂载 U 盘

插入 U 盘后，系统会自动识别并挂载 USB 存储。若无法识别，需确认 U 盘文件系统格式、电源供电和 USB HOST 配置。

## 屏幕旋转

若系统启用重力传感器或方向配置，应用界面可随方向变化而旋转。部分应用可能不支持自动旋转。

## 拍照摄像

连接摄像头并确认驱动加载后，可使用系统相机或测试程序预览图像。不同摄像头需要匹配对应驱动、供电和设备树配置。

## 有线以太网上网

连接网线后，系统会通过有线以太网获取 IP。可在设置中查看网络状态，也可通过命令确认：

```bash
ifconfig
ping 8.8.8.8
```

## 红外遥控

红外接收头可用于遥控器输入。实际按键映射以系统按键表和驱动配置为准。

## 4K 视频播放和 HDMI 显示

RK3399 支持高性能视频解码和 HDMI 输出。连接 HDMI 显示器后，可用于外接大屏显示、视频播放和调试验证。

## 开关机与休眠唤醒

I3399 支持开关机、复位和休眠唤醒。硬件按键与系统电源管理需要配合设备树、PMU 和系统服务配置。
