# 硬件设计

本页只保留底板设计时需要注意的硬件规则，不重复接口说明和引脚定义。

## 电源设计

X3399 核心板采用 3.3V 供电。用户需要给第 51、52 管脚提供 3.3V/4.3A 直流电，给第 42 管脚提供 3.3V/300mA 直流电，核心板才能正常工作。

注意：第 51、52 脚的主 3.3V 供电和第 42 脚的副 3.3V 供电不能合并，否则可能出现关机状态未知等问题。

- 42 脚：3.3V/300mA 电源输入，任何情况下都需要常供电，以保证 PMU 处于工作或待命状态。
- 51、52 脚：3.3V/4.3A 电源输入，只在开机时需要供电，关机后电压为 0。
- 53、84、182 脚：核心板公共地。
- 120 脚：1.8V/1.5A 电源输出，可用于底板 1.8V 外设供电，休眠或关机后为 0V。

## USB 设计

RK3399 有两路 HOST 口和两路 TYPE-C 口。I3399 中一路 TYPE-C 通过 USB3.0 接口引出，另一路通过 TYPE-C 接口引出。TYPE-C 既可以作为 HOST，也可以作为 DEVICE，并具备显示扩展能力。

USB2.0 默认速率可达 480Mbps，USB3.0 最高可达 5Gbps，对 PCB 走线要求更高。USB 差分线必须等长走线，阻抗建议匹配 90Ω，并保证完整参考平面。

### USB 差分对

| 差分管脚编号 | 差分管脚名称 |
| --- | --- |
| 114、115 | USB3_DM、USB3_DP |
| 116、117 | HOST0_DM、HOST0_DP |
| 118、119 | HOST1_DM、HOST1_DP |
| 109、110 | USB3_SSRXP、USB3_SSRXN |
| 107、108 | USB3_SSTXP、USB3_SSTXN |
| 105、106 | TYPEC0_DM、TYPEC0_DP |

| 97、98 | TYPEC0_RX1N、TYPEC0_RX1P |


## HDMI 设计

RK3399 自带 HDMI 控制器，支持 HDMI2.0。核心板第 85 到 92 脚为 HDMI 相关 4 对差分线，必须等长走线，阻抗匹配 100Ω，否则可能出现画面丢色、闪烁或间歇性断连。

## EDP 设计

RK3399 自带 EDP 接口。EDP 包含 5 组差分对，对应核心板第 135 到 144 脚。EDP 总带宽可达 21.6Gbps，适合驱动 2K、4K 等高分辨率屏幕，PCB 走线需要等长差分，阻抗匹配 100Ω。

## MIPI 设计

RK3399 支持 DSI 和 CSI。DSI 可用于 MIPI 显示屏，CSI 可用于 MIPI 摄像头。MIPI 数据传输率远高于 LVDS，走线时必须保证差分等长、阻抗匹配 100Ω，并尽量减少过孔和参考平面中断。
