# 故障排查

按 12V/4.0V/5V/3.3V/1.8V → 核心板 VSYS → 复位 → 串口日志 → 启动介质 → 外设的顺序排查，具体检查项如下。

| 现象 | 检查项 |
| --- | --- |
| 无启动/无串口 | 输入源、各电源轨、复位、J21 接线和 115200 参数；保存日志 |
| 下载工具不识别 | 配套驱动、数据线、J10、USB 下载开关、按住按键再上电 |
| 编译/打包失败 | ALPS/MSSI 同级目录、依赖、解释器、磁盘空间及首个错误 |
| 屏幕黑屏 | J17/U39/CN2 电源、背光、复位、LK2/Kernel 驱动及时序 |
| 摄像头无预览 | C-PHY/D-PHY 匹配、电源、MCLK、I2C、复位/PWDN 和驱动 |
| 以太网无地址 | RJ45 连接/指示灯、RTL8111H、PCIe/pinctrl、网络设置 |
| USB/TF 不识别 | VBUS/卡电源、USB 开关、限流、接触和文件系统 |
| 高负载不稳定 | 适配器容量、压降、温度、散热及外设负载 |

记录主板型号/批次、X8883BV3_20260725 原理图版本、固件版本、修改文件、复现步骤、完整串口日志与测试条件，便于复核。
