# 核心板引脚定义

X3566CV2 核心板采用 200PIN 邮票孔方式，引脚间距 1.0mm。下表保留硬件手册中的完整 200PIN 定义，便于底板设计、复用功能检查和驱动调试。

![X3566CV2 核心板结构图](./x3566-core-board-size.png)

:::note
所有 MIPI 差分对无法复用为普通 GPIO 口。每一组 GPIO 都有对应电压域，大多数 GPIO 组预留两个可选电阻用于电压域设置，通常为 1.8V 或 3.3V。由于核心模块的通用性，同型号核心模块会根据尾缀区分不同电阻跳线，用户应按实际使用场景订货。
:::
