# Android 使用指南

本页整理 X3568 Android 系统启动后的常用功能操作，包括命令终端、音视频、WIFI/BT、外设挂载、摄像头、以太网、HDMI、开关机与休眠唤醒。

## 命令终端

将串口连接主板调试串口，进入 Android 系统后可通过串口查看系统终端打印。

## 播放 MP3

确保外置 SD 卡或 U 盘中存在 MP3 文件，打开音乐播放器后，系统会自动识别音频文件，点击相应文件即可播放。

## 播放视频

Android 图库会在外置存储中自动扫描可识别的视频和图片文件。点击带播放符号的视频文件即可播放。

## 使用 WIFI 上网

X3568 主板自带 WIFI/BT 二合一模块，无需额外 USB WIFI。进入设置中的 `Network & Internet`，打开 Wi-Fi，选择目标网络并输入密码即可联网。

## 使用蓝牙传输数据

进入设置中的 `Connected devices -> Bluetooth`，打开蓝牙并搜索设备。与手机或其他蓝牙设备配对后，可通过图库或文件管理器进行蓝牙文件分享。

## 使用蓝牙播放音乐

准备蓝牙音箱并切换到蓝牙模式。在主板蓝牙设置中搜索并配对音箱，配对成功后播放音视频，声音会通过蓝牙音箱输出。

## 使用 USB 鼠标键盘

启动主板后，将 USB 鼠标、键盘或无线接收器接到 USB HOST 接口，即可操作 Android 界面。

## 挂载 TF 卡

系统启动后会自动将 TF 卡挂载到 `/storage/` 目录，并根据 UUID 识别挂载点。

## 挂载 U 盘

插入 U 盘后，系统会将 U 盘自动挂载到 `/storage` 目录，可通过 `ls /storage` 查看挂载目录。

## 拍照摄像

点击 Android 应用中的相机进入预览模式，点击拍照按钮即可拍照，界面中可切换拍照和录像功能。

## 有线以太网上网

将可正常联网的网线连接到网口座，网口指示灯正常闪烁后，即可通过有线网络上网。

## 红外遥控

X3568 默认硬件支持红外遥控，可通过遥控器操作 Android 界面，适用于机顶盒类场景。

## HDMI 显示

HDMI 显示可将 LCD 上的视频还原到带 HDMI 接口的电视或显示器，支持 1080P、2K 高清视频，并同步传输音频。

## 开关机

X3568 使用 PMU 进行电源管理。接入 12V 电源适配器后，主板会自动上电进入系统。进入系统后长按开机键会弹出关机确认界面。

## 休眠唤醒

进入 Android 后，轻按开关机键，屏幕熄灭并进入休眠。再次轻按开关机键可唤醒主板。
