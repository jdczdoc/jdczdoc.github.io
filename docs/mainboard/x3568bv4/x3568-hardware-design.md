# 硬件设计

本页只保留底板设计和外设连接时需要注意的硬件规则，不重复接口说明和引脚表。

## 电源设计

X3568V4 主板使用 12V 直流电源供电。底板或外设扩展时应保证输入电源电流充足，电源走线尽量加宽，并保持良好的地回流路径。

核心板侧关键电气参数：

| 项目 | 参数 |
| --- | --- |
| 3.3V 输入电压 | 3.3V / 2A |
| RTC 输入电压 | 3V / 0.6uA |
| 输出电压 | 3.3V / 1.5A，可用于底板供电 |
| 工作温度 | -10~70 度 |
| 储存温度 | -10~40 度 |

## USB 设计

RK3568 提供 USB HOST2.0、HOST3.0 和 OTG 接口。OTG 与其中一路 USB3.0 存在复用关系，实际产品设计时要明确拨码开关或硬件复用状态。

PCB 走线建议：

- USB2.0 D+/D- 走等长差分线，差分阻抗按 90Ω 控制；
- USB3.0 TX/RX 高速差分对需要严格等长、完整参考平面和阻抗控制；
- OTG 口用于烧录时，要保证 VBUS、ID、D+/D- 和 ESD 防护设计正确。

## 显示接口设计

RK3568 支持 DSI、LVDS、EDP 和 HDMI 输出。X3568V4 左侧接口可通过软件切换 DSI/LVDS，右侧接口通过核心板 0R 电阻硬件分配 DSI/EDP。

设计时要注意：

- DSI / LVDS / EDP 高速差分线需要等长、阻抗控制和连续参考平面；
- 背光电源、背光使能、PWM 调光和触摸 I2C / 中断 / 复位信号应与屏规格匹配；
- HDMI 差分线需要按高速信号规则走线，并保留良好的 ESD 防护。

## 摄像头接口设计

Camera 接口为 30PIN 摄像头接口。不同 OV 系列摄像头需要核对电源电压、复位、PWDN、MCLK、I2C 和 MIPI/并口数据线定义。更换摄像头时应同步检查设备树、驱动、电源时序和时钟配置。

## 以太网设计

X3568V4 支持两路千兆以太网，PHY 使用 YT8521CA。设计时需要注意 RGMII 信号长度、时钟、复位、PHY 地址、电源和网络变压器布线。网口附近建议保留可靠 ESD 和共模防护。

## PCIE / SATA 设计

PCIE 和 SATA 属于高速接口，需要严格控制差分阻抗、线长匹配、参考平面连续性和连接器布局。外设兼容性问题通常与时钟、电源、复位时序和高速线质量相关。

## GPIO / 串口扩展

GPIO、UART、I2C、SPI、PWM 等接口存在复用关系。扩展外设前应先确认对应引脚的默认功能、IO 电压域、上拉/下拉状态和设备树配置。
