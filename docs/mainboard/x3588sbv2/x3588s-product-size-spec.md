# 尺寸与规格

## 产品尺寸

X3588S mini ITX 主板采用标准 Mini-ITX 尺寸，规格参数表中标注为 17cm × 17cm，适配通用 ITX 电脑机箱。

![X3588S mini ITX 产品尺寸图](./x3588s-product-size.png)
