# 配置清单

## 标准配置

- X821V30主板一套。
- 配套网盘资料，由客服提供。

## 选配附件

| 配件 | 建议规格/数量 |
| --- | --- |
| TF卡 | 8GB或更大，1张 |
| 锂电池 | 3.7V单节，1个 |
| USB线 | Type-C数据线，1根 |
| 喇叭 | 8Ω/3W，1个 |
| 麦克风 | 2组 |
| LED灯 | 1组 |
| LCD | 2.0英寸，240×320，1块 |
| 摄像头 | 与当前SDK传感器配置匹配，1个 |

摄像头、LCD和触摸器件必须同时核对接口电压、引脚顺序、驱动型号和设备树配置，不能只按连接器外观选型。
