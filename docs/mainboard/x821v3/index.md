# X821主板

X821V30是一款基于全志V821双RISC-V SoC的AI智能体主板。板载64MB DDR2、128MB Flash、2.4GHz Wi-Fi、BLE、音频、MIPI CSI、SPI LCD和触摸接口，软件平台为Linux 5.4/Tina Linux 5.0。
