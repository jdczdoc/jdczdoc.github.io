# 配置清单

## 标配硬件清单

- i6818 开发板一套，带 8 寸 1024 × 768 电容触摸屏。
- 5V / 2A 电源适配器 1 个。
- USB 数据线 1 根。
- 串口转接板 1 个。
- 串口延长线 1 根。
- 开发板资料，通过网盘下载。

## 选配硬件清单

- 8G TF 卡。
- 支持 x210、x4412、x4418、x6818 的 HDMI 线。
- USB 转串口延长线。
- USB 3G 上网卡。
- USB 摄像头。

## 开发板资料清单

i6818 开发板标配通过网盘下载资料，内容包括开发板配套源码、开发环境搭建说明、使用手册、详细实例教程、核心板和底板电路原理图、元器件封装库、烧录工具等。
