# 硬件接口定义

以下接口编号和信号定义按本型号手册整理。连接前应核对板上丝印、连接器方向及实际硬件版本。

## 接口总览

| 硬件接口介绍 |  | 硬件接口介绍 |
| --- | --- | --- |
| 标号 | 名称 | 说明 |
| 【1】 | 独立按键 | boot按键，用于maskrom或强制升级 |
| 【2】 | 独立按键 | 复位按键 |
| 【3】 | 独立按键 | PWRKEY |
| 【4】 | 遥控接收头接口 | 用于外接遥控头（部分客户需求） |
| 【5】 | PWR LED接口 | 用于外接机箱的POWER按键及LED指示灯 |
| 【6】 | RTC | 实时时钟电池接口，3V供电 |
| 【7】 | CAMERA摄像头接口 | 外接MIPI通讯的摄像头 |
| 【8】 | WIFI-BT | 双频WIFI6、BT模块 |
| 【9】 | 触摸接口 | 触摸屏接口，I2C通讯协议 |
| 【10】 | 显示接口 | 显示接口，EDP通讯协议 |
| 【11】 | 显示接口 | 显示接口，双8位LVDS显示接口 |
| 【12】 | 背光接口 | 屏幕背光接口（如果不用该接口，大屏机器可以从该接口输入12V直流电给整板供电） |
| 【13】 | HOST2.0 | USB2.0扩展口，通过外接小板可扩展1到4路HOST2.0接口 |
| 【14】 | USB扩展口 | USB HOST2.0接口，4PIN 1.25mm立式贴片座 |
| 【15】 | Line IN | 音频线性输入接口 |
| 【16】 | HOST2.0 | USB HOST2.0接口 |
| 【17】 | Phone/MIC | 带耳麦耳机输出接口 |
| 【18】 | GMAC | 千兆以太网接口 |
| 【19】 | HOST3.0 | USB HOST3.0接口 |
| 【20】 | HDMI OUT | HDMI输出接口 |
| 【21】 | HDMI IN | HDMI输入接口，可接高清HDMI摄像头 |
| 【22】 | TypeC接口 | 标准TypeC接口，用于程序下载等 |
| 【23】 | DC插座 | 12V直流电源输入接口 |
| 【24】 | 风扇电源座 | DC12V，GPIO可控风扇电源座 |
| 【25】 | 喇叭接口 | 外置左声道扬声器 |
| 【26】 | 音频接口 | 外置左右声道扬声器（用于外挂功放音频） |
| 【27】 | 喇叭接口 | 外置右声道扬声器 |
| 【28】 | UART2 | UART2，TTL电平接口，默认为调试串口 |
