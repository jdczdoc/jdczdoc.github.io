# Android 使用指南

手册说明该系列产品预装或支持 Android 12.0。以下仅整理手册明确描述的系统操作；具体菜单名称可能随固件版本和定制界面变化。

## Wi-Fi 连接

1. 打开系统“设置”。
2. 开启 Wi-Fi。
3. 选择目标无线网络并输入密码。

## 蓝牙连接

1. 打开“设置”并进入 **Connected devices**。
2. 点击 **Pair new device** 搜索蓝牙设备。
3. 选择目标设备并完成配对。

## 以太网连接

1. 在“设置”中进入 **Network & internet**。
2. 打开 **Ethernet**。
3. 插入网线后查看设备显示的 IP 地址及 IP 模式。

## 查看存储信息

在“设置”中打开 **Storage**，查看系统存储使用情况。显示的可用容量会受到系统分区和预装软件占用影响。

## 天线注意事项

使用 Wi-Fi 和蓝牙前，应在对应天线座连接天线。无线信号可用性和覆盖范围受周围无线环境、天线性能及安装环境影响。

## 导播软件

部分手册列出的导播软件安装包名称为 `Guide_Station_release_vx.x.x.apk`。是否预装及具体版本以实际交付固件为准。
