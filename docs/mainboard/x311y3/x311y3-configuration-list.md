# 配置清单

## 标配硬件

- 开发板一套，带 7 寸 1024×600 电容触摸 MIPI 液晶模组。
- 12V/2A 电源适配器 1 个。
- Type-C 数据线 1 根。
- USB 转串口转接板 1 个。
- 网盘资料链接，通过官方 WIKI 查询。

## 选配硬件

- 喇叭。
- 8GB TF 卡。
- 10.1 寸 1280×800 LVDS 液晶模组。
- 1300 万像素摄像头。
- USB 摄像头。
