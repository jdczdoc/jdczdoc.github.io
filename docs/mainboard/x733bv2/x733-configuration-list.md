# 配置清单

| 类别 | 可选项/说明 |
|---|---|
| 开发板型号 | X733BV2 |
| 源码板型 | `x733bv2` |
| 处理器 | 全志 A733 |
| CPU 架构 | Cortex-A76 + Cortex-A55，八核 |
| 内存 | 2 GB / 4 GB / 8 GB |
| eMMC | 4 GB / 8 GB / 16 GB / 32 GB / 64 GB |
| PMIC | AXP318W |
| 输入电源 | 12 V DC，建议 3 A；支持电池接口 |
| 无线 | AW869A Wi-Fi 6 / Bluetooth 5.2 |
| 有线网络 | RTL8211F 千兆以太网 |
| 视频输出 | HDMI OUT、MIPI DSI、eDP |
| 视频输入 | HDMI IN，经 LT6911C 转 MIPI CSI |
| 存储扩展 | TF 卡、M.2 |
| 系统 | Android 13；其他版本以实际 SDK 为准 |

## 标准配套

- X733BV2 开发板
- 12 V 电源适配器
- Type-C 数据线
- USB 转串口工具
- SDK、固件和烧录工具资料

## 可选配件

- TF 卡和 M.2 存储设备
- MIPI DSI/eDP 屏及触摸模组
- MIPI CSI 摄像头
- 双路麦克风、扬声器和耳机
- 电池包与匹配的温度检测线
- 12 V 风扇和散热片
