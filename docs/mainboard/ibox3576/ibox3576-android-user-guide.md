# Android 使用指南

## 命令终端

连接调试串口并启动 Android 后，可以通过串口进入 Android 命令终端。

## 音频和视频播放

将音频或视频文件放入 TF 卡、U 盘或本地存储后，可通过 Android 自带音乐、图库等应用进行播放。

## Wi-Fi 上网

IBOX3576 主板板载 Wi-Fi / BT 二合一模块。进入系统设置，打开 Wi-Fi，选择无线网络并输入密码即可连接。

## 蓝牙传输和蓝牙音频

打开蓝牙后，可搜索手机、蓝牙音箱等设备并完成配对。配对后可传输文件，也可通过蓝牙音箱播放音频。

## USB 鼠标键盘

将 USB 鼠标或键盘接到 USB HOST 接口，即可操作 Android 界面。

## TF 卡和 U 盘挂载

系统启动后会自动挂载 TF 卡和 U 盘到 `/storage/` 目录，并根据 UUID 识别存储设备。

## 屏幕旋转

主板集成重力传感器，支持根据方向变化进行屏幕旋转。部分应用可能不支持自动旋转。

## 拍照摄像

连接摄像头后，打开相机应用即可进行预览、拍照和录像。

## 有线以太网上网

将网线接入网口，网口指示灯正常闪烁后，Android 系统即可通过有线网络联网。

## HDMI 显示

HDMI 输出可将显示和音频同步输出到电视或显示器。

## 开关机与休眠唤醒

接入 12V 电源后主板上电启动。进入系统后，长按开机键可弹出关机界面；轻按电源键可休眠，再次轻按可唤醒。
