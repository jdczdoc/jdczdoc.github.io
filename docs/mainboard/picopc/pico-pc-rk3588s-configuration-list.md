# 配置清单

## 标配硬件清单

- Pico PC RK3588S 主板一块。
- 5V Type-C 电源或供电线。
- Android / Linux / Ubuntu / Debian / Buildroot 镜像资源。
- 用户手册、烧录工具、驱动工具和源码资料。

## 选配硬件清单

- 7 寸 MIPI 屏（1024 × 600）。
- MIPI CSI 摄像头。
- TF 卡。
- USB 鼠标、键盘、U 盘。
- 散热器。
- USB 摄像头。
- 4G 模块或其他扩展模块。
- 调试串口线。
