# 配置清单

## 标配

- X507开发板一套，硬件手册描述为配7寸1024×600电容触摸RGB液晶模组。
- 12V/2A电源适配器1个。
- Micro USB数据线1根。
- 串口线1根。
- 网盘资料链接或官方WIKI资料。

## 选配

- 外置喇叭。
- 8GB TF卡。
- 10.1寸1280×800 LVDS液晶模组。
- 200万像素摄像头。
- USB转串口线。
- USB摄像头。

## 收货检查

收到硬件后，建议先核对底板版本、核心板版本、内存/eMMC容量、无线模块型号、屏幕接口和电源适配器规格，再选择对应SDK和设备树配置。
