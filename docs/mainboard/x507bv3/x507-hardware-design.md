# 硬件设计

## 设计依据

底板设计的最终依据应为X507CV1核心板原理图、T507芯片数据手册和当前交付SDK。硬件手册给出了引脚功能，但没有完整给出所有高速接口的阻抗、长度匹配和电源时序约束。

## 电源

- 开发板外部输入为12V，标配适配器为12V/2A。
- 核心板159、160脚为5V输入；163、164脚为3.3V输出。
- 核心板参数表标称5V/2A输入和3.3V/1.5A输出。
- 底板使用3.3V输出给外设供电前，应核对峰值负载、上电时序和PMU配置。
- RTC输入标称3V/0.6µA。

## IO电平

原手册没有给出完整的GPIO电压域表。任何外接GPIO、UART、I2C、SPI、LCD和摄像头信号，在投板前都必须从原理图确认实际IO电平，不能仅根据接口名称假定为3.3V。

## USB

- USB0为OTG接口，USB1、USB2、USB3为USB 2.0 Host差分对。
- 开发板实体提供两路Type-A Host和一路Micro USB OTG。
- OTG口用于PhoenixSuit固件下载。
- 原手册未给出差分阻抗和走线长度约束，应按T507参考设计执行。

## HDMI

HDMI信号包括CEC、DDC、HPD、TMDS时钟和3组TMDS数据差分对。原手册未给出具体阻抗及组内/组间等长范围，应按T507 HDMI参考设计和PCB板厂阻抗计算结果执行。

## RGB/LVDS显示

RGB和LVDS信号存在复用。显示模式由底板电阻配置、连接器、设备树和显示驱动共同决定。调整屏幕前至少需要确认：

- IO电平和屏供电。
- 背光电源、使能极性和PWM极性。
- RGB/LVDS复用方式。
- 分辨率、像素时钟和时序参数。

## 摄像头

- MIPI CSI接口提供4 lane差分数据和控制信号。
- 并行摄像头接口提供BT.656/NCSI类信号。
- 摄像头的AVDD、DVDD、IOVDD、MCLK、RESET和PWDN时序必须按具体Sensor规格设计。

## 千兆以太网

核心板引出RGMII信号，开发板板载RTL8211F。自定义底板时应重点核对RGMII时钟方向、TX/RX时延配置、PHY复位、25MHz参考时钟和PHY IO电源。

## PCIe与4G模块

PCIe用于扩展4G通信模块，并配有SIM卡槽。除PCIe差分对外，还需要确认模块供电峰值、复位、唤醒、USB备用接口和SIM线路ESD保护。

## 资料勘误

硬件手册的开发板功能列表写“2路USB Host 2.0”，核心板接口参数表写“3路Host 2.0”。两者并不必然冲突：核心板可引出3组Host信号，但开发板实体只安装2个Type-A Host座。设计时应区分SoC/核心板资源与开发板已装接口。
