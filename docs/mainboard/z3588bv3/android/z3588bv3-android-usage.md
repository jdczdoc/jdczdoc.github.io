# Android 使用与功能验证

## 串口终端与 ADB

Android 用户手册建议将串口连接到开发板 DEBUG 调试接口，系统启动后可通过串口查看终端输出。手册没有在该章节统一给出串口波特率；请按实际 DEBUG 线材/SDK 配置设置。

在 PC 端确认 ADB 连接：

```bash
adb devices
adb shell
```

如设备未列出，检查 USB OTG 连接、系统 USB 调试开关及 PC 端驱动。

## 网络连接

### Wi-Fi

打开 Android 设置中的 Network & Internet，启用 Wi-Fi，选择无线网络并输入密码连接。

### 蓝牙

进入 Settings → Connected devices → Bluetooth，打开蓝牙并搜索目标设备。选择设备并完成配对后，可通过系统分享菜单发送文件，也可连接蓝牙音箱播放音频。

### 有线以太网

将可用网线连接到板载 RJ45 接口，观察接口指示灯，并在系统网络设置中确认获取到 IP 地址。

## USB 与存储

- USB 鼠标/键盘：连接 USB Host 接口后可操作 Android 界面。
- TF 卡：Android 手册说明启动后自动挂载到 `/storage/`。
- U 盘：插入 USB Host 后，系统自动挂载到 `/storage/` 下的相应目录。

## 音视频与显示

- 音乐：将 MP3 文件放入外置存储，在音乐播放器中选择播放。
- 视频/图片：图库应用会扫描外置存储中的媒体文件；选择视频文件后播放。
- 摄像头：手册描述通过系统相机应用进入预览并拍照/录像。但是否可用取决于摄像头模组、设备树与驱动配置。
- HDMI：手册描述 HDMI 可输出视频和音频，并列出 1080P、4K、8K，以及 720P、576P、480P 等格式。具体分辨率与刷新率由显示设备、SDK 和输出配置决定。
- 休眠唤醒：短按电源键可进入休眠，再次短按唤醒；长按电源键可从系统菜单执行关机。

## 测试程序的限制

Android 手册明确说明：该版本 i3588 尚未移植其通用 Android 测试程序。因此，手册中后续 LCD、触摸、LED、蜂鸣器、背光、按键、电池、ADC、重力传感器、音频、摄像头和网络测试界面，不能据此认定 Z3588BV3 当前固件内置这些测试程序。实际验证应使用当前 SDK 已提供的工具和对应硬件驱动。
