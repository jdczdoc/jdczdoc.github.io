# 配置清单

| 类别 | 可选项/说明 |
|---|---|
| 开发板型号 | I527BV3 |
| 源码板型 | `i527bv3` |
| 核心板 | X527CV2，200 PIN 邮票孔 |
| 处理器 | T527/T527N/A527 系列，实际以核心板 BOM 为准 |
| 内存 | 2 GB / 4 GB LPDDR4X |
| eMMC | 4 GB / 8 GB / 16 GB / 32 GB / 64 GB 等 |
| 输入电源 | 12 V DC，建议 3 A |
| 无线 | AW869A Wi-Fi 6 / Bluetooth 5.2 |
| 有线网络 | RTL8211F 千兆以太网 |
| 视频输出 | HDMI OUT、eDP、LVDS、MIPI DSI |
| 视频输入 | HDMI IN，经 LT6911C 转 MIPI CSI |
| 系统 | Android 13/14、Linux，以实际 SDK 版本为准 |

## 标准配套

- I527BV3 开发板
- 12 V 电源适配器
- Type-C 数据线
- USB 转串口工具
- SDK/固件资料

## 可选配件

- TF 卡
- MIPI/LVDS/eDP 屏及触摸模组
- 摄像头模组
- 喇叭、麦克风和耳机
- PCIe 4G 模块与天线
- M.2 存储设备
- 12 V 风扇
